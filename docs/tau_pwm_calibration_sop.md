## 0. 目的与成功定义

### 0.1 目的

在无电流环硬件的前提下，标定并验证电压前馈公式中的常数，使固件能用：

\[
\mathrm{PWM}(\%) = \mathrm{sign}(\tau)\cdot D_{\mathrm{dead}}
  + 100\cdot\frac{\dfrac{R}{K_t}\tau + K_b\,\omega}{V_{\mathrm{batt}}}
\]

把控制环输出的 \(\tau\)（N·m）映射成驱动器可接受的占空比（%）。  
（若固件占空比接口已是 0~100，系数 100 按实际接口约定取；关键是 \(V/V_{\mathrm{batt}}\) 与 \(D_{\mathrm{dead}}\) 量纲一致。）

### 0.2 整份 SOP 过关（最终成功）

同时满足：

1. 左右轮各自有一套 \(R,K_t,K_b,D_{\mathrm{dead}}\)（可先共用再分填）  
2. \(K_t\) 与 \(K_b\) **交叉自洽**（§7）  
3. 开环 \(\tau_{\mathrm{ref}}\) 验证误差 **≤ ±20%**（§8，目标 ±10%）  
4. 电池压降策略已选定（固定常数或必须 ADC）  
5. 参数表签字冻结，方可写 `applyTorque` / 算 LQR

## 1. 人员 / 工具 / 安全

### 1.1 工具清单（缺一项就开不了工）

| 工具 | 用途 | 最低要求 |
| --- | --- | --- |
| 数字万用表 | 测 \(V\)、串联测 \(I\) | 电流档 ≥ 额定堵转电流；直流电压 0.01 V 分辨率 |
| 可调直流电源（可选但强烈推荐） | 低电压堵转 / 可控空载 | 能限流；显示 \(V,I\) 更佳 |
| 已知质量砝码 ≥ 3 档 | 挂重测 \(K_t\) | 质量误差 ≤ 1%；建议 50g / 100g / 200g 量级按电机能力选 |
| 细绳 + 轮缘缠绕 | 挂重 | 绳不打滑；力矩臂 = 轮半径 |
| 卡尺 / 卷尺 | 复核 \(r\) | 0.1 mm |
| 台架 / 夹具 | 堵转固定轴 | 轴绝对不能转 |
| 串口监视（PlatformIO monitor） | 读 `ticks` / `v` / `eff` | 开环 `m 0` |
| 记时器 | 堵转通电限时 | 手机即可 |

### 1.2 安全（每次开工前口头确认）

- [ ] 堵转通电 **≤ 2 s**，间歇冷却 ≥ 10 s；绕组发烫立即停  
- [ ] 堵转电压远低于额定（建议先 2~3 V 或低 PWM）  
- [ ] 车轮离地或轴固定，勿夹手  
- [ ] 标定全程 **`m 0` 开环**，禁止平衡模式边站边标  
- [ ] 测死区前确认 `kMotorDeadband={0,0}`，否则门槛被前馈抬高测不准

### 1.3 固件前置

| 项 | 要求 |
| --- | --- |
| 模式 | `m 0`，`s` 清零 |
| 死区前馈 | 临时 `kMotorDeadband={0,0}` 烧录（测完再恢复） |
| 测速换算 | `kMPerTick`、`kWheelRadiusM` 已是当前电机实测值 |
| 遥测 | 能看到 `ticks`、`v`（m/s）、`eff` |

换算（本车当前默认）：

\[
\omega\ (\mathrm{rad/s}) = \frac{v\ (\mathrm{m/s})}{r},\quad r = 0.0375\,\mathrm{m}
\]

\[
v\ (\mathrm{m/s}) = \mathrm{ticks/s}\times k_{\mathrm{MPerTick}}
\]

若用 1 s 窗口 \(\Delta\mathrm{ticks}\)，则 \(\mathrm{ticks/s}=\Delta\mathrm{ticks}\)。

| # | 检查项 | 方法 | 过关 |
| --- | --- | --- | --- |
| A1 | 编码器方向 | 开环 `e 20`，轮朝前进时 `v`/`ticks` 同号为正 | 左右皆正 |

## 3. 步骤 SOP-1：堵转标定 \(R\)

### 3.1 准备

- 电机轴 / 轮**完全固定**（夹具；手按不可靠）  
- 确认 \(\omega=0\)（编码器 1 s 内 ticks 变化 = 0）  
- 左右轮**分开测**

### 3.2 操作

对每个轮、每个电压点：

1. 设定低电压 \(V\)（建议：2.0 / 2.5 / 3.0 V；或等价低 PWM + 实测 VM）  
2. 通电，在 **0.5~1.5 s** 内读稳态电流 \(I\)（避开冲击尖峰）  
3. 断电冷却 ≥ 10 s  
4. 同一 \(V\) 重复 3 次

### 3.3 记录表（每轮一张）

**轮：□ L  □ R** 日期：________ VM 空载：________ V

| 序号 | \(V\) (V) | \(I_1\) | \(I_2\) | \(I_3\) | \(\bar I\) | \(R=V/\bar I\) (Ω) | 通电时间 (s) |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | | | | | | | ≤2 |
| 2 | | | | | | | ≤2 |
| 3 | | | | | | | ≤2 |

定稿：\(R_{\mathrm{L}}=\) ______ Ω \(R_{\mathrm{R}}=\) ______ Ω （多组平均）

### 3.4 验收关卡（Gate R）

| # | 判据 | 阈值 | 不过则 |
| --- | --- | --- | --- |
| R1 | 同 \(V\) 三次 \(I\) 相对极差 | \(\lvert I_{\max}-I_{\min}\rvert/\bar I \le 5\%\) | 重测；查夹具是否松动 / 发热 |
| R2 | 不同 \(V\) 算出的 \(R\) 相对极差 | ≤ 8% | 电压是否含线阻/驱动压降；改测电机端子电压 |
| R3 | 左右轮 \(R\) 差 | ≤ 15% | 可分填；>25% 查接线/电机是否异常 |
| R4 | \(R\) 量级合理 | 通常几 Ω 量级（视电机） | 差一个数量级 → 电流档/单位错 |

**额外检测（推荐）**：通电瞬间若轴有任何蠕动，本点作废（\(\omega\neq0\)，\(R=V/I\) 不成立）。

**Gate R 未过 → 禁止进入 §4。**

## 4. 步骤 SOP-2：空载标定 \(K_b\)

### 4.1 准备

- 轮**完全离地**，空转  
- `kMotorDeadband={0,0}`  
- 每组稳定 ≥ 2 s 再采 1 s 窗口 ticks

### 4.2 操作

1. 对 PWM（或等效 \(V=D\cdot V_{\mathrm{batt}}\)）取 **≥ 4 点**，建议覆盖：30% / 50% / 80% / 100%（避开死区附近的 20% 若非线性严重可作参考点但不进回归）  
2. 每点采 3 次 1 s 窗口，取平均 \(\bar\omega\)  
3. 用万用表测该工况下电机端有效电压 \(V\)（优先）或 \(V=D\cdot V_{\mathrm{batt}}\)（次选）  
4. 过原点拟合：\(V = K_b\,\omega\) → \(K_b = \sum(V\omega)/\sum(\omega^2)\)（或表格线性回归强制过原点）

可复用 [`stage0_motor_bench.md`](stage0_motor_bench.md) 空载表，但**必须补测电流或端电压**，并按当前 `kMPerTick` 重算 \(\omega\)。

### 4.4 验收关卡（Gate Kb）

| # | 判据 | 阈值 | 不过则 |
| --- | --- | --- | --- |
| Kb1 | 同点三次 \(\omega\) 极差 | ≤ 3% | 轴承/供电不稳；重测 |
| Kb2 | \(V\)-\(\omega\) 近似过原点直线 | \(R^2 \ge 0.98\)（≥4 点） | 去掉近死区点；查电压测点 |
| Kb3 | 各点 \(K_b^{(i)}=V_i/\omega_i\) 相对极差 | ≤ 10% | 高占空比饱和则只用中段 3 点 |
| Kb4 | 左右 \(K_b\) 差 | ≤ 10% | 可分填；过大查减速比/轮径 |
| Kb5 | 与铭牌/经验同量级 | 不差 10× | 查 \(r\)、`kMPerTick`、rad/s 换算 |

**Gate Kb 未过 → 禁止进入 §5（挂重仍可做，但交叉检验会失败）。**

## 5. 步骤 SOP-3：挂重标定 \(K_t\)（独立力矩通道）

### 5.1 原理与陷阱

准静态：\(\tau = m g r\)，\(K_t=\tau/I\)。  
必须满足：**加速度 ≈ 0**（匀速上升或恰好顶住不下滑）。  
加速拉起会高估电流需求 → \(K_t\) 偏低。

### 5.2 操作

1. 绳绕轮缘，力臂确认 = \(r\)（绳在轮槽中心）  
2. 挂质量 \(m\)（至少 3 档），\(\tau=mgr\)  
3. 缓慢加大电压/PWM，直到：  
   - **优先**：砝码**匀速**上升；或  
   - **次选**：刚好顶住静止（静摩擦会偏大，仅作核对）  
4. 串联测电流 \(I\)，取稳定段  
5. 每档重复 2 次

**轮：□ L  □ R** \(r=\) ______ m \(g=9.81\)

| \(m\) (kg) | \(\tau=mgr\) (N·m) | 工况(匀速/顶住) | \(I_1\) | \(I_2\) | \(\bar I\) | \(K_t=\tau/\bar I\) |
| ---: | ---: | --- | ---: | ---: | ---: | ---: |
| | | | | | | |
| | | | | | | |
| | | | | | | |

定稿：\(K_{t,\mathrm{L}}=\) ______ N·m/A \(K_{t,\mathrm{R}}=\) ______ N·m/A

### 5.4 验收关卡（Gate Kt）

| # | 判据 | 阈值 | 不过则 |
| --- | --- | --- | --- |
| Kt1 | 同档两次 \(I\) 极差 | ≤ 8% | 是否真匀速；重做 |
| Kt2 | 不同 \(m\) 的 \(K_t\) 极差 | ≤ 12% | 静摩擦主导 → 只用「匀速上升」点 |
| Kt3 | 绳不打滑、力臂稳定 | 目视 + \(\omega\) 平稳 | 打滑本点作废 |
| Kt4 | \(K_t\) 与 \(K_b\) 交叉见 §7 | — | — |

**Gate Kt 未过 → 禁止冻结参数；可先完成死区/压降，但 §8 终验会挡。**

## 6. 步骤 SOP-4：死区 \(D_{\mathrm{dead}}\)

### 6.1 操作（左右、正反各测）

1. `kMotorDeadband={0,0}`，`m 0`  
2. 从 0 起每次 +0.5% 或 +1%（近门槛用细步进）  
3. 记录**持续转动**（≥1 s 不停）的最小 \|PWM\|  
4. 正转、反转各测；左右分开

| --- | ---: | ---: | ---: |
| L | | | |

### 6.3 验收关卡（Gate D）

| # | 判据 | 阈值 | 不过则 |
| --- | --- | --- | --- |
| D1 | 正反差 | ≤ 2%（占空比点） | 齿轮箱单向摩擦大，可取 max |
| D2 | 左右差 | ≤ 3% | 分填；过大查装配 |

## 7. 交叉自洽检验（Gate X）——测量是否准确的核心检测

国际单位下理想有 \(K_t = K_b\)（数值相等）。实车因齿轮效率、测点不同会有偏差，用相对误差：

\[
e_{tk} = \frac{\lvert K_t - K_b\rvert}{\max(K_t,K_b)}
\]

| 结果 | 判定 | 动作 |
| --- | --- | --- |
| \(e_{tk} \le 15\%\) | **通过** | 公式里 \(K_t\) 用挂重值；\(K_b\) 用空载值（推荐） |
| \(15\% < e_{tk} \le 30\%\) | **有条件通过** | 以挂重 \(K_t\) 为准；空载 \(K_b\) 仍用于反电动势项；在笔记标明偏差 |
| \(e_{tk} > 30\%\) | **失败** | 禁止进入终验；按下面排障 |

### 7.1 排障顺序（\(e_{tk}\) 过大时）

```text
1) 复查 ω：r、kMPerTick、单位 (rad/s vs rpm)
2) 复查空载 V：是否测了电机端电压（含驱动压降）
3) 复查挂重：是否匀速、力臂是否 = r、质量是否准确
4) 复查 R：堵转是否真 ω=0、电流是否稳态
5) 左右轮是否测混 / 减速比是否一致
```

### 7.2 辅助一致性检测（推荐做）

由模型：空载近似 \(V\approx K_b\omega\)；堵转 \(R=V/I\)。  
任选一点中等 PWM 空载，测 \(I_{\mathrm{nl}}\)，应有：

\[
I_{\mathrm{nl}} \approx \frac{V - K_b\omega}{R} \quad\text{（接近 0~小正数）}
\]

| 判据 | 阈值 |
| --- | --- |
| 算出的 \(I_{\mathrm{nl,pred}}\) 与实测差 | ≤ 0.15 A 或相对 ≤ 30%（空载电流本身很小，看绝对差） |

若预测电流为负或差很大 → \(K_b\) 或 \(R\) 至少有一个系统性偏差。

**Gate X 未过 → 禁止进入 §8。**

## 8. 步骤 SOP-5：电池压降策略（Gate V）

| 工况 | \(V_{\mathrm{batt}}\) | 备注 |
| --- | ---: | --- |
| 空载静置 | | |
| 双轮中高 PWM 空转 | | |
| 单轮短时近堵转（≤1 s） | | |

\[
\delta = \frac{V_{\mathrm{no\_load}}-V_{\mathrm{loaded}}}{V_{\mathrm{no\_load}}}

| \(\delta\) | 策略 |
| --- | --- |
| ≤ 5% | 可用固定 \(V_{\mathrm{batt}}=V_{\mathrm{no\_load}}\)（或两者平均） |

## 9. 步骤 SOP-6：开环终验（Gate F）——整条映射是否准

本步是「检测机制」的终点：不改平衡环，只在开环命令 \(\tau_{\mathrm{ref}}\)，看实际力矩是否跟上。

### 9.1 固件最小条件

若 `applyTorque` 尚未合入，可用**手工等价验证**（不写新功能也能验常数）：

1. 选 \(\tau_{\mathrm{ref}}\)、测当前 \(\omega\)  
2. 手算 \(\mathrm{PWM}_{\mathrm{cmd}}\)（用 §0 公式）  
3. 开环下发该 PWM（`e` / `el` / `er`）  
4. 串联测 \(I\)，得 \(\tau_{\mathrm{act}}=K_t I\)（挂重定稿的 \(K_t\)）  
5. 对比 \(\tau_{\mathrm{act}}\) 与 \(\tau_{\mathrm{ref}}\)  

有 `applyTorque` 后：直接命令 \(\tau_{\mathrm{ref}}\)，重复 4–5。

### 9.2 测试矩阵（每轮至少）

轮离地；每点稳定后读 \(I,\omega\)。

| \(\tau_{\mathrm{ref}}\) (N·m) | 预期工况 | \(\omega\) | \(I\) | \(\tau_{\mathrm{act}}=K_tI\) | 误差% |
| ---: | --- | ---: | ---: | ---: | ---: |
| 小（刚过死区） | 慢转 | | | | |
| 中 | 中速 | | | | |
| 较大（勿超热） | 高速/大电流 | | | | |
| 负的中等 | 反转 | | | | |

误差定义：

\[
e_\tau = \frac{\tau_{\mathrm{act}}-\tau_{\mathrm{ref}}}{\tau_{\mathrm{ref}}}\times 100\%
\]

### 9.3 验收关卡（Gate F）

| # | 判据 | 阈值 |
| --- | --- | --- |
| F1 | 中等 \(\lvert\tau_{\mathrm{ref}}\rvert\) 点 | \(\lvert e_\tau\rvert \le 20\%\)（目标 ≤10%） |
| F2 | 正反对称 | 正/负中等点误差符号不系统偏向同一侧超过 15% |
| F3 | 转速越高误差不爆炸 | 高速点 \(\lvert e_\tau\rvert \le 25\%\)（反电动势项主导；超了查 \(K_b\)） |
| F4 | 左右轮各自过 F1 | 都过才算整车过 |

**不合格返工映射：**

| 现象 | 优先复查 |
| --- | --- |
| 全速系误差同号偏大 | \(R/K_t\) 或 \(V_{\mathrm{batt}}\) |
| 仅高速差 | \(K_b\)、端电压 |
| 仅低速差 | \(D_{\mathrm{dead}}\)、静摩擦 |
| 左右一个过一个不过 | 该侧 \(R/K_t\) 重测 |

**Gate F 未过 → 禁止用这套常数算 LQR / 合入正式固件。**
