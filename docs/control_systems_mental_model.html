控制思路入门：什么时候建状态方程

给「没系统学过控制理论、但已经在拧平衡车增益」的人：先搭思维骨架，再谈矩阵。 核心问题只有一个——我现在卡在流程的哪一步，这一步要不要状态方程。

0. 你缺的往往不是公式，而是“工序图”

控制教材一上来就写 \(\dot x=Ax+Bu\)，好像全世界都已经默认你知道： 为什么要 \(x\)、\(A\) 从哪来、什么时候才需要它。若你没有这张工序图，就会感觉：

  • 牛顿定律也会用，为什么突然要“状态”？
  • 阶段 3 手调 PD 明明能站，为什么阶段 5 又要建模算 \(K\)？
  • 拉格朗日、状态方程、LQR、离散化……谁先谁后？

把控制想成工程流水线，而不是一堆并列公式，会轻松很多：

1
说清要控什么：输入能拧什么旋钮，输出要盯什么量，什么叫“表现好”。
2
选要不要模型：纯试凑 / 基于模型设计。手调 PID 可以无完整模型；LQR 必须有模型。
3
若要模型：先物理（运动学+动力学）→ 微分方程 →（常）再写成状态方程。
4
若要线性设计：在工作点线性化 → \(A,B\) → 极点配置或 LQR。
5
落到计算机：离散化、采样周期、执行器单位、传感器噪声。
6
实车校准模型假设：参数、死区、饱和——模型错则“最优”也错。

和本仓库的对应

阶段 3/4 ≈ 流水线第 1 步 + 跳过完整模型的试凑反馈；阶段 5 ≈ 补上 3–6 步。所以不是“PD 错了才上 LQR”，而是“先证明硬件能站，再换用模型算出的增益”。

1. 五个词先对齐（比背定义重要）

1.1 被控对象（Plant）

真实物理东西：电机+车体+轮子+地面。你不能改定律，只能改加在它上面的输入。

1.2 输入 \(u\)（你能命令的）

例：PWM 占空比、目标电流、目标力矩 \(\tau\)。同一辆车，把 \(u\) 定义成 % 还是 N·m，后面的 \(B\) 矩阵完全不同——这不是数学游戏，是单位契约。

1.3 输出 \(y\)（你能测到的、或关心的）

例：IMU 俯仰角、编码器速度。输出不一定等于状态；有时 \(y\) 只是状态的一部分。

1.4 状态 \(x\)（“为了预测未来，现在必须记住的最小信息”）

这句话比任何教材定义都好用。问自己：

  • 若我突然忘掉当前倾角，还能不能正确算下一步力矩？——不能，所以 \(\theta\) 是状态（或必须能从别的量推出来）。
  • 若我忘掉“今天星期几”，影响平衡吗？——不影响，不是状态。

对理想无摩擦轮式倒立摆，四元组 \((\theta,\dot\theta,s,\dot s)\) 通常够用。电流环很慢时，电流也可能要当状态——那是执行器增广。

1.5 扰动 \(d\)（你不想要但存在的）

推一把、坡度、风、电池压降。反馈的价值很大一部分是抗扰动；前馈则是“已知扰动先抵消”。 

   扰动 d
      │
      ▼
  u ──▶ [ 被控对象 ] ──▶ y
          ▲    │
          │    └─ 内部状态 x 在演化
          └──────── 控制器（看 y 或 x，产 u）

先会画这张框图，再往里面填公式。状态方程就是在描述方框内部 \(x\) 怎么变。

2. 一条总流程（从问题到公式）

每次面对新控制任务，按这个顺序问，而不是先翻哪本讲 \(A,B\) 的书：

  1. 目标：站稳？跟速度？定点？要多快、允许多大误差？
  2. 执行器：我真正能改的物理量是什么？（电压 / 电流 / 力矩）
  3. 传感：我能直接得到哪些量？缺的要不要观测器？
  4. 要不要第一性原理模型？
    • 不需要：试凑 PID / 手调状态反馈（你阶段 3/4）。
    • 需要：为了算增益、做仿真、做最优、做稳定性证明。
  5. 若需要模型：选坐标 → 运动学约束 → 动力学（牛顿或拉格朗日）→ ODE。
  6. 是否写成状态方程：要做现代控制（极点配置、LQR、卡尔曼）时，写成 \(\dot x=f(x,u)\)。
  7. 是否线性化：要用线性工具（LQR、波特图、根轨迹）时，在工作点线性化。
  8. 离散与实现：采样周期、单位、限幅、滤波。

关键误区

“做控制 = 一上来写状态方程”。错。状态方程是第 6 步的一种书写格式，服务于后面要用的工具。阶段 3 能站，说明你已经在用反馈思想，只是还没用矩阵形式表达植物理。

3. 什么时候需要构建状态方程？

3.1 一句话判据

当你要用“以状态为核心”的设计或分析工具时，就需要状态方程；当你只靠试凑和输入输出感觉时，可以不写。

3.2 需要写状态方程的典型场景

你想做的事为什么需要状态形式
LQR / LQG代价和 Riccati 都定义在 \(x,u\) 上
极点配置（全状态反馈）要设计 \(A-BK\) 的特征值
可控性 / 可观性检查判据吃的是 \(A,B,C\)
状态观测器 / 卡尔曼滤波估计的是 \(x\)
多输入多输出耦合系统传递函数矩阵很烦，状态更干净
仿真里统一积分数值积分器吃一阶式 \(\dot x=f(x,u)\)

3.3 可以先不写的场景

你在做的事通常够用的工具
单回路调速、调温PID + 阶跃响应手感
平衡车阶段 3 扶正物理直觉 + \(k_\theta,k_{\dot\theta}\) 试凑
只关心频域裕度的 SISO波特图 / 传递函数（也不一定要状态）
硬件排障、死区、接线根本不需要状态方程

3.4 “微分方程”和“状态方程”是什么关系？

动力学直接给你的常常是二阶（或更高阶）微分方程，例如：

\[ l\ddot\theta = g\theta - \ddot s \]

这已经是模型。状态方程不是新物理，只是把高阶式改写成一阶向量形式，方便统一处理：

\[ \dot{\mathbf{x}} = f(\mathbf{x},u) \quad\text{或线性}\quad \dot{\mathbf{x}}=Ax+Bu \]

类比

二阶 ODE 像“用段落写的故事”；状态方程像“把故事拆成条目列表，方便数据库和算法处理”。故事内容应相同，只是格式变了。

3.5 决策小结

问自己三个问题

  1. 我是否要用 LQR / 极点配置 / 观测器？→ 是，则需要状态方程。
  2. 我是否只有试凑增益、且已经够稳？→ 可以暂不写，但要知道物理直觉从哪来。
  3. 我是否连二阶物理方程都没有？→ 先别写 \(A,B\)，先补动力学（牛顿或拉格朗日）。

4. 怎么建状态方程：可操作配方

不要背“选取状态变量的三条定理”。按下述配方做即可。

4.1 配方（通用）

A
列出广义坐标：独立的几何自由度。平衡车平面模型常用 \(s,\theta\)。
B
写出动力学：得到含 \(\ddot s,\ddot\theta\) 的方程（牛顿或拉格朗日）。
C
解出最高阶导数：把 \(\ddot s,\ddot\theta\) 写成更低阶量与 \(u\) 的函数。
D
定义状态：通常把每个广义坐标及其一阶导都放进 \(x\)。
例：\(x=[\theta,\dot\theta,s,\dot s]^\top\)。
E
拼一阶式：\(\dot\theta\) 的方程就是“第二态本身”；\(\ddot\theta\) 的方程变成 \(\dot x_2=\ldots\)。
F
定义输出：\(y=Cx\)（测什么写什么）。

4.2 小例子：质量–弹簧–阻尼

物理：

\[ m\ddot q + c\dot q + kq = u \]

配方 C：

\[ \ddot q = -\frac{k}{m}q -\frac{c}{m}\dot q +\frac{1}{m}u \]

配方 D–E：令 \(x_1=q,\;x_2=\dot q\)

\[ \dot x_1 = x_2,\qquad \dot x_2 = -\frac{k}{m}x_1-\frac{c}{m}x_2+\frac{1}{m}u \]
\[ A=\begin{bmatrix}0&1\\ -k/m&-c/m\end{bmatrix},\quad B=\begin{bmatrix}0\\ 1/m\end{bmatrix} \]

你看：没有任何玄学。状态方程 = “把二阶拆成两个一阶，再打包成矩阵”。

\(A,B\) 不是“矩阵乘法化简”出来的

对号入座：\(\dot x_1=0\cdot x_1+1\cdot x_2+0\cdot u\)，\(\dot x_2=\ldots\)，系数排进 \(A,B\)。用 \(Ax+Bu\) 验算应回到原一阶式。

\(Ax+Bu\) 算完是两行向量；第一行是 \(x_2\)，表示 \(\dot x_1=x_2\)（位置变化率=速度），没有“丢掉”。第二行才是牛顿定律给出的加速度。

读 ODE：\(x(t+\Delta t)\approx x+\Delta t(Ax+Bu)\)。下一拍由 \(Ax\)（自然漂移）+ \(Bu\)（操纵） 共同决定；你只能选 \(u\)。赶到远处状态通常要一串输入，不是一拍搞定。

ODE = Ordinary Differential Equation（常微分方程）。\(\dot{\mathbf{x}}\) 是对时间的一阶导；\(\dot x=f(x,u)\) 是一阶（向量）形式。

4.3 平衡车极简版（加速度当输入）

\[ \ddot\theta = \frac{g}{l}\theta - \frac{1}{l}u_a,\quad u_a=\ddot s \]
\[ x=\begin{bmatrix}\theta\\ \dot\theta\end{bmatrix},\quad A=\begin{bmatrix}0&1\\ g/l&0\end{bmatrix},\quad B=\begin{bmatrix}0\\ -1/l\end{bmatrix} \]

扩展到四态时，只是再塞进 \(s,\dot s\)，并把 \(u\) 从 \(\ddot s\) 换成 \(\tau\)（\(B\) 列随之改变）。工序不变。

4.4 状态顺序是约定，不是物理

\([\theta,\dot\theta,s,\dot s]\) 与 \([s,\theta,\dot s,\dot\theta]\) 都对，但 \(K\) 向量顺序必须跟着变。写代码前把顺序写成注释钉死。

4.5 输出方程 \(y=Cx+Du\)

\(\dot x=Ax+Bu\) 描述内部演化；\(y=Cx+Du\) 描述测到/关心的量。\(D\) 通常为 0。全状态可测时 \(C=I\)。这与可控性矩阵 \(\mathcal{C}=[B\ AB\ \cdots]\) 不是同一个 \(C\)。

4.6 从加速度行补全 \(A\)（预习）

若已有加速度仿射 \(\ddot q=\mathbf{A}_a x+\mathbf{B}_a u\)，完整 \(A\) 还要两行运动学：\(\dot s=\dot s\)、\(\dot\theta=\dot\theta\)——对准速度分量填 1，其余 0。详见问答归档 §2–3。

5. 什么时候要线性化？

5.1 非线性是常态

真实：\(\sin\theta\)、饱和、摩擦。完整模型是 \(\dot x=f(x,u)\)。线性工具（LQR、经典根轨迹）吃的是 \(A,B\)。

5.2 何时线性化

  • 你准备用 LQR / 线性极点配置 / 线性卡尔曼；
  • 工作点附近运动幅度小（直立附近几度到十几度）；
  • 你需要局部稳定性、带宽等线性指标。

5.3 何时不要只靠线性模型

  • 摔倒大角度恢复、坐地再站；
  • 频繁顶饱和；
  • 要证明全局稳定（需要别的工具）。

5.4 线性化在算什么

在平衡点 \((x_e,u_e)\)（直立常取 \(x_e=0,u_e=0\)）：

\[ A=\frac{\partial f}{\partial x}\Big|_{e},\qquad B=\frac{\partial f}{\partial u}\Big|_{e} \]

对倒立摆，\(\sin\theta\approx\theta\) 就是最常见的手工线性化。不必每次都写雅可比符号，但要知道本质是一阶泰勒。

6. 开环与闭环：状态方程放在哪

开环：  命令 u ──▶ 对象 ──▶ y     （不看结果）
闭环：  命令 r ──▶ 控制器 ──▶ u ──▶ 对象 ──▶ y
                      ▲                    │
                      └────── 反馈（y 或 x）┘

对象的状态方程描述开环植物理（倒立摆开环不稳，\(A\) 有正特征值）。 控制器另写：例如 \(u=-Kx\) 或 PID。合在一起才得到闭环 \(\dot x=(A-BK)x\)。

调参时你在改什么

拧 \(k_\theta\) 时，你是在改控制器，不是改物理 \(A\)。LQR 则是：固定 \(A,B\) 与 \(Q,R\)，自动生成一套 \(K\)。物理参数测错 → \(A,B\) 错 → \(K\) 最优在错模型上。

7. PID、状态反馈、LQR：同一谱系上的三档

档你在用什么信息增益从哪来本仓库
经典 PID主要一个误差 \(e=r-y\)手拧 / 经验公式刻意不用误差 PID 模板做平衡
状态反馈多个状态 \(x\)手拧各 \(k_i\)阶段 3/4
LQR同样用 \(x\)模型 + \(Q,R\) 算出 \(K\)阶段 5

关键认知：LQR 不是另一种硬件结构，它是“状态反馈增益的一种算法来源”。所以固件可以同一套 \(u=\sum k_i(x_i-x_{\mathrm{ref},i})\)，只换 \(k\) 表。

7.1 为什么倒立摆不爱用“误差 PID 模板”

模板 \(u=k_p(e)\) 且 \(e=\theta_{\mathrm{des}}-\theta\) 时，前倾 \(\theta>0\) 会给出负控制——轮子往后，更倒。平衡需要“朝倒的方向追”。仓库约定 \(k=\partial u/\partial x>0\)，避免套错符号。

7.2 传递函数视角（可选）

SISO 时，状态空间与传递函数 \(G(s)=C(sI-A)^{-1}B\) 可互转。多状态、多目标时状态空间更自然。你现阶段不必先精通波特图，也能做 LQR；但要知道：经典控制看的是 \(G(s)\)，现代控制看的是 \(A,B,C\)。

8. 决策树与自检问题

场景 A：车还站不稳

先别建 LQR 状态方程去算 \(K\)。查 IMU、电机方向、安全限幅、手调 \(k_\theta\) 符号。状态方程解决不了接线反了。

场景 B：手调能站，想换模型增益

现在需要：物理参数 → 动力学 → 状态方程 → 线性化 → 离散 LQR。同时力矩接口单位要正确。

场景 C：只想理解“为什么前倾要前加速”

一张二阶式 \(l\ddot\theta=g\theta-\ddot s\) 就够，不必先上四维 \(A\)。

场景 D：仿真与实车差很多

回到模型假设（\(l\)、摩擦、\(\tau\) 标度、\(dt\)），不是先改 Riccati 求解器。

8.1 自检题（建立元认知）

  1. 我当前的 \(u\) 定义是什么单位？
  2. 我有没有已经写出二阶物理方程？还是在空谈 \(A,B\)？
  3. 我要用的工具是试凑还是 LQR？后者才强制状态方程。
  4. 线性化工作点是哪？偏离多大还能信？
  5. 离散周期和设计是否一致？

9. 落到你的两轮平衡车

阶段 3/4（已走过）
  目标：站、走
  模型：脑子里有极简式即可
  控制器：手调状态反馈
  状态方程：非正式，但结构已是 u = k·x

阶段 5（正准备）
  目标：同一结构，增益改由 LQR 给
  必须补：
    ① 动力学 / 拉格朗日或牛顿 → ODE
    ② 状态方程 + 线性化 → A,B
    ③ 离散 LQR → K
    ④ u 的单位 = N·m（执行器）
概念本车取值意识
状态\(\theta,\dot\theta,s,\dot s\)（顺序与脚本钉死）
输入阶段 5：力矩；阶段 3/4：曾用 %
输出IMU + 编码器（近似全状态可测）
何时写 \(A,B\)算 LQR 之前；不是拧手调增益之前
参考成形kff、软停：不属于 \(A,B\)，属于控制器外围

10. 常见卡点（没系统学控制时的典型坑）

卡点疏通方式
把状态方程当成新物理它只是 ODE 的一阶向量写法
还没动力学就填 \(A\)\(A\) 的数来自线性化后的物理系数
以为 LQR 会自动处理死区/坡度线性模型没有的东西，\(K\) 也不会变出来
混淆对象模型与控制器\(A,B\) 是车；\(K\) 是你
传递函数和状态空间打架同系统两种表示；现阶段优先状态空间
离散/连续混用固件采样周期决定用 DARE 还是 CARE
