> 对应 [`stage5.md`](stage5.md) 步骤 ①；高度一律相对**轮轴中心**（车轮圆心），轴上方为正。  
> 若从地面量：\(h = h_{\mathrm{离地}} - r\)，\(r=\) 轮半径。

---

## 0. \(M\) / \(m\) 怎么拆（先读再称）

经典两轮倒立摆里：

| 符号 | 包含什么 | 实车怎么称 |
| --- | --- | --- |
| **\(M\)（车体）** | 会「跟着车身俯仰」的质量：骨架、电池、开发板、驱动板、**电机定子/壳体（整颗电机可不拆）**、线材等 | **拆掉左右车轮**后上秤；**电机留在车上** |
| **\(m\)（轮侧）** | 两只轮子 +（可选）转子转动惯量的等效质量 | 单独称两轮；转子惯量没有现成设备时先只用两轮质量，或沿用「电机+轮」整称再拆 |

**结论：\(M\) 要去掉车轮，但不要去掉电机。**  
电机壳体固定在车架上，属于车体；轮子才是相对车体转动的那部分。

本车历史粗分（[`balance_gain_theory.md`](balance_gain_theory.md#this-robot)）：电机+轮 ≈ 0.515 kg，上层 ≈ 0.260 kg，整车 ≈ 0.775 kg——下面表格用来重测、细分。

由分段质量估车体质心高度（相对轮轴）：

\[
l_M \approx \frac{\sum m_i h_i}{\sum m_i}
\]

若模型的 \(l\) 要用**整车含轮**质心，再把轮（\(h_{\mathrm{wheel}}\approx 0\)）并进去加权即可；多数 LQR 脚本里 \(l\) 是**车体质心到轮轴**，用 \(l_M\) 即可。

### 3.1 「电机转子等效」是什么（不是把电机再称一次）

\(m\) 里写的「两轮 + 电机转子等效」指的是：

- **两轮**：真实平动/转动质量（上表称出来即可）  
- **电机转子等效**：转子有转动惯量 \(J_{\mathrm{m}}\)，经减速比反映到轮轴后，在「轮子平动」模型里等价成一截质量 \(m_{\mathrm{rot}}\)  

**不是**把整颗电机质量加进 \(m\)（那样会和 \(M\) 重复）。  
电机壳体/减速箱外壳仍在 \(M\)；只有**跟着电枢转的那部分惯量**才折算进 \(m\)。

单侧折算（输出轴 = 轮轴，减速比 \(n=\omega_{\mathrm{电机}}/\omega_{\mathrm{轮}}\)）：

\[
J_{\mathrm{out}} = J_{\mathrm{m}}\, n^{2}
\quad\Rightarrow\quad
m_{\mathrm{rot,1}} = \frac{J_{\mathrm{out}}}{r^{2}} = J_{\mathrm{m}}\frac{n^{2}}{r^{2}}
\]

两轮车：\(m_{\mathrm{rot}}=2\,m_{\mathrm{rot,1}}\)（左右各一颗）。  
本车 P30：\(n=30\)，\(r\approx0.0375\,\mathrm{m}\)。

### 3.2 怎么估算 \(J_{\mathrm{m}}\) / \(m_{\mathrm{rot}}\)（由易到难）

| 档 | 做法 | 适用 |
| --- | --- | --- |
| **A. 先忽略转子** | \(m=\) 两轮质量之和；电机全进 \(M\) | **推荐起步**；\(m\) 略偏小，用 Q/R 留裕度 |
| **B. 铭牌/手册** | 查 MG513 电枢惯量 \(J_{\mathrm{m}}\)（kg·m² 或 g·cm²），代入上式 | 有数据时最干净 |
| **C. 粗经验** | 转子质量取电机质量的 ~10%～20%，等效在电枢半径 \(r_{\mathrm{a}}\) 上：\(J_{\mathrm{m}}\approx m_{\mathrm{rotor}} r_{\mathrm{a}}^{2}/2\)，再 \(\times n^{2}/r^{2}\) | 无手册时数量级估计；\(r_{\mathrm{a}}\) 约几 mm，算完看 \(m_{\mathrm{rot}}\) 是否离谱 |
| **D. 台架辨识** | 已知 \(\tau\) 或电流，空载加速 \(\dot\omega\)：\(J\approx\tau/\dot\omega\)（含齿轮），再扣轮的 \(J_{\mathrm{wheel}}=m_{\mathrm{wheel}}r^{2}\) | 有电流/力矩后做 |

**数量级直觉（P30，\(n=30\)）**：\(n^{2}=900\)，很小的 \(J_{\mathrm{m}}\) 也会被放大；但玩具减速电机 \(J_{\mathrm{m}}\) 本身极小，算完 \(m_{\mathrm{rot}}\) 常常只有**几十克到与单轮同量级**，很少超过两轮质量很多。若粗算得到 \(m_{\mathrm{rot}}\) 比整车还重，多半是 \(J_{\mathrm{m}}\) 或单位错了。

### 3.3 实车建议怎么填

1. **第一次算 LQR**：\(m=\) 左右轮质量之和，\(m_{\mathrm{rot}}=0\)（档 A）。  
2. 电流/挂重通了以后，有空再做档 D，把 \(m_{\mathrm{rot}}\) 补进 \(m\) 重算 \(K\)。  
3. 不要把「电机+轮 0.515 kg」整段塞进 \(m\)，同时 \(M\) 又含电机——会双计。

## 5. 称重顺序（建议）

```text
1) 整车（带轮）称一次 → 总重
2) 拆左右轮，分别称轮 → 填 §3
3) 去轮车体上秤 → 应等于 M（§2 合计）
4) 再拆电池 / 板 /（可选）骨架分称 → 填 §2 各行 + 量 h_i
5) 算 l_M，写入 §4
```

不必为测 \(M\) 把电机从车上拧下来；**只拆轮**即可。
