# 阶段 5 规划：电流传感器力矩测量 / 力矩闭环

> 前提变更：准备加装**电流传感器**，用 \(I\) 直接估/控力矩 \(\tau=K_t I\)，不再把「无电流采样的电压前馈」当作唯一路径。  
> 对照：无电流方案 [`tau_pwm_calibration_sop.md`](tau_pwm_calibration_sop.md) · 总路线 [`stage5.md`](stage5.md) · AT8236 衰减 [`pwm_fast_slow_decay.md`](pwm_fast_slow_decay.md)

本文是**规划流程**（选型 → 接线 → 标定 → 固件分层 → 切 LQR）。  
**2026-08-14 起：P0～P2 已有实车数据，下文 §1 / §5～§10 按实测改过；§2～§4 留作归档。**  
原则不变：不改 `BalanceController` 单位、不上 LQR，直到电流环过 Gate C。

## 0. 为什么加电流传感后路径要重画

| | 无电流（旧） | **有电流（本规划）** |
| --- | --- | --- |
| 力矩怎么来 | 用 \(R,K_b,V,\omega\) 反推，误差大 | \(\tau = K_t I_{\mathrm{meas}}\)，直接 |
| 必须精标的量 | \(R,K_t,K_b,D_{\mathrm{dead}},V_{\mathrm{batt}}\) 全套 | **\(K_t\) + 电流通道标定**为主；\(R/K_b\) 降级为可选前馈 |
| 执行器目标 | 开环 τ→PWM 电压公式 | **优先：电流内环跟踪 \(I_{\mathrm{ref}}=\tau_{\mathrm{ref}}/K_t\)** |
| LQR 的 \(u\) | 易与真实力矩脱节 | 可真正贴近 N·m |

有电流后，阶段 5 的硬门槛从「电压前馈常数全对」变成「**电流测得准 + \(K_t\) 标得准 +（可选）电流环带宽够**」。

## 2. P0：硬件选型与接线规划（✅ 已完成，归档）

### 2.1 需求（按本车约束写死）

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 路数 | **左右各 1**，共 2 | 差速 / 单侧故障可诊断 |
| 方向 | **双向**（能测正负电流） | 前进/后退、再生/刹车都有电流反号 |
| 量程 | 建议峰值 ≥ **±5~10 A**（按实车堵转电流留 1.5× 余量） | 堵转标定与摔倒恢复瞬间会冲电流 |
| 带宽 | 模拟前端 ≥ **数 kHz**；数字滤波后给控制用 ≤ 1 kHz | AT8236 PWM 有纹波；控制环 200 Hz 只需平均电流 |
| 隔离 | 分流+放大或霍尔隔离均可 | 注意与 ESP32 GND / 电机功率地布局 |
| MCU | ESP32 ADC（或外置 ADS1115 等） | 若用片上 ADC：注意衰减、噪声、采样时刻 |

### 2.2 推荐传感器形态（选型决策）

按「省事 → 准」排序，现场择一：

| 方案 | 例子 | 优点 | 风险 |
| --- | --- | --- | --- |
| A. 霍尔电流模块 | ACS712 / ACS724 等 | 接线简单、隔离好 | 零点温漂、噪声大，要好好校零 |
| B. 高端/低端分流 + 电流检测运放 | INA240 / INA180 + 分流电阻 | 带宽好、线性好 | 布线/共模电压要设计对；低端分流改地回路 |
| C. 驱动芯片自带电流镜 | 视驱动是否引出 | 集成 | AT8236 **通常不直接给精确双向传感**，本车默认外挂 |

**本规划默认：方案 A 或 B，外挂两路，串在各电机电源回路（推荐测**电机相电流**或半桥供电支路，且与 PWM 同步采样策略一致）。**

### 2.3 接在哪里（概念）

```text
电池 VM ──┬── AT8236(L) ── 电机 L
          │       ▲
          │    电流传感 L（测该桥输出支路电流，符号与前进一致）
          │
          └── AT8236(R) ── 电机 R
                  ▲
               电流传感 R
```

注意：

1. **慢衰减 / 快衰减**会改变续流路径，采样点选错会出现「占空比高但电流读数怪」。选型后在 P1 用示波器或高速采样核对。  
2. 传感器输出 → ESP32 ADC 引脚：**远离电机线绞合、加 RC、共地单点**。  
3. `config.h` 预留：`kCurrentAdcGpio[2]`、量程、零点、符号。

### 2.4 P0 验收（Gate H）

- [x] 左右各一路：ACS712-05B，L=`GPIO34`，R=`GPIO35`  
- [x] 前进为正电流（`kCurrentSign` 已对齐）  
- [x] 不与 PWM 23/22、13/12、I2C 18/19 冲突  

**Gate H 已过。**

## 3. P1：电流通道标定（ADC → 安培）（⚠ 有条件通过）

目标：得到可靠的

\[
I_{\mathrm{meas}} = k_{\mathrm{adc}}\,(\mathrm{ADC}-\mathrm{ADC}_0)
\]

（或厂家 mV/A 曲线 + 实测斜率）。**这一步测的是「安培准不准」，还不是力矩。**

### 3.1 子步骤

| 步骤 | 内容 | 做法 |
| --- | --- | --- |
| P1-1 零点 | 电机使能、PWM=0 或断开负载 | 采 1~2 s 平均 → `ADC0`；上电每次可重校 |
| P1-2 极性 | 开环小正转 `e +20` | \(I\) 应为正；反了软件翻符号 |
| P1-3 斜率 | 串入实验室电流表 / 钳表 | ≥3 个稳态电流点，拟合 \(k_{\mathrm{adc}}\) |
| P1-4 滤波 | 原始 ADC 含 PWM 纹波 | 一阶低通或移动平均；控制用截止建议 **50~100 Hz**（先别滤太狠） |
| P1-5 同步（可选增强） | 在 PWM 周期固定相位采样 | 减小纹波折合误差；P3 再做也不迟 |

### 3.2 记录与验收（Gate I）

| # | 判据 | 阈值 |
| --- | --- | --- |
| I1 | 零点重复（上下电 3 次） | 折合 ≤ **50 mA** |
| I2 | 与外接电流表比（中等电流） | \(\lvert I_{\mathrm{sens}}-I_{\mathrm{meter}}\rvert / I_{\mathrm{meter}} \le **5%**\) |
| I3 | 正负对称 | 同 \|PWM\| 正反，\|I\| 差 ≤ 8% |
| I4 | 静止噪声峰峰值 | 折合 ≤ **100 mA**（滤波后） |
| I5 | 200 Hz 控制环读取不拖垮 `hz` | `ovr` 仍≈0 |

**2026-08-14**：I2 外接表不做；I1/I4 在**重启校零后**静止约 ±0.05 A、峰峰值可接受。未校准时静止假电流 ±1.5 A——后续固件必须能停转重校零。  
`iL`/`iR` 遥测已有。斜率维持 185 mV/A。

## 4. P2：力矩常数 \(K_t\) 标定（✅ 有条件冻结）

> **可执行 SOP + 空白记录表**：[`current_to_torque_calibration_sop.md`](current_to_torque_calibration_sop.md)（Gate I → Gate Kt-I）。

有可靠 \(I\) 后，挂重变成标准做法：

\[
\tau = m g r,\qquad K_t = \frac{\tau}{I_{\mathrm{meas}}}
\]

### 4.1 流程（比无电流版更干净）

1. 轮离地或台架；绳 + 已知 \(m\)；力臂 \(=r\)  
2. 缓慢加大 PWM，直到**匀速**拉起（加速度≈0）  
3. 读稳态 \(I_{\mathrm{meas}}\)（用已校准通道，可同时记外接表交叉）  
4. ≥3 档质量 × 左右轮 × 正反（反可用反向挂或反转）  
5. 定稿 \(K_{t,L}, K_{t,R}\)

### 4.2 验收（Gate Kt-I）

| # | 判据 | 阈值 |
| --- | --- | --- |
| K1 | 同档两次 \(K_t\) 差 | ≤ 8% |
| K2 | 不同质量算出的 \(K_t\) 极差 | ≤ 12% |
| K3 | 左右差 | ≤ 15%（可分填） |
| K4 | 与可选空载 \(K_b\)（若做） | \(e_{tk}\le 20\%\) 为佳；失败以**挂重 \(K_t\)**为准 |

可选交叉（降低优先级）：

- 堵转：短时测 \(R\approx V/I\)（排障用）  
- 空载：\(V\approx K_b\omega\)（给电流环电压前馈用，不是力矩主路径）

### 4.3 本阶段交付物

```text
I_meas 通道参数（零点、斜率、符号、滤波）
Kt_L, Kt_R
验证：τ_hat = Kt * I 在挂重工况与 mgr 差 ≤ 15%
```

**2026-08-14 已冻 \(K_{tL}=0.23,\,K_{tR}=0.22\)。** 细节与表见 SOP。不必再挂重挡 P3。

## 5. P3：后续固件（按实测压缩）

不要一次上「LQR + 电流环 + 新单位」。**刀 1 并进第一次改固件**；刀 2 先只开环跟踪电流；刀 3 才动平衡出口。

### 5.0 刀 0 — 停转重校零（P3 开工条件）

挂重已证明：上电校零不稳 → 静止 ±1.5 A，\(K_t I\) 全废。

- `m 0` 且 PWM=0、轮不动时重采 \(V_0\)（串口一条指令，或并进现有 `s`）
- 校完静止 \(\lvert iL\rvert,\lvert iR\rvert \lesssim 0.10\,\mathrm{A}\) 才允许电流环积分
- 遥测继续打零点电压，便于发现又漂了

### 5.1 刀 1 — 观测 \(\hat\tau\)（与刀 2 开环同一批代码）

| 项 | 内容 |
| --- | --- |
| `config.h` | `kTorquePerAmp[2] = {0.23f, 0.22f}` |
| 遥测 | `tauL/tauR = Kt * current()`，平衡仍 `applyRawPwm` |

### 5.2 刀 2 — 电流 PI（先开环 `I_ref`，`m 1` 仍 %）

```text
I_ref  ←  开环：el/er 解释为安培
           以后刀3：τ_ref / Kt
    ↓
PI：  PWM += Kp e + Ki ∫e ,  e = I_ref − I_meas
    ↓
现有 applyRawPwm / 慢衰减 AT8236 20 kHz
    ↑
I_meas = current()（已低通）
```

| 项 | 按本车取值 |
| --- | --- |
| 环频率 | **与控制环同 200 Hz**，写在 `WheelActuator` 内；`ovr` 明显变差再谈加频 |
| \(I_{\max}\) | **2.5 A**（ACS712 ±5 A；手册堵转 3.2 A 不作持续限） |
| 前馈 | 无 \(IR+K_b\omega\) |
| 死区 | 刀 2 开环**保留现有 % 死区**；切 τ 后再收成一层 |
| 开环指令 | `m 0`：`el`/`er`/`e` 单位改 **A**（`er 0.4` ≈ 240 g 匀速电流） |

**Gate C（分两档）**

| # | 何时 | 判据 |
| --- | --- | --- |
| C1 | 刀 2，轮离地 | 阶跃 \(I_{\mathrm{ref}}\)（0.2 / 0.4 / 0.8 A）稳态误差 ≤ 10%，不啸叫；`hz=200` |
| C2 | 刀 3 之后 | \(\tau_{\mathrm{ref}}\) 阶跃时 \(\hat\tau\) 跟上 |
| C3 | 刀 3 切入平衡 | 不比纯 % 手调更抖；`ovr` 不恶化 |
| C4 | 刀 2 即可 | \(\lvert I\rvert>I_{\max}\) 削 \(I_{\mathrm{ref}}\) |

### 5.3 刀 3 — `applyTorque(τ)` + 平衡仍手调
