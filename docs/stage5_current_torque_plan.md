# 阶段 5 规划：电流传感器力矩测量 / 力矩闭环

> 前提变更：准备加装**电流传感器**，用 \(I\) 直接估/控力矩 \(\tau=K_t I\)，不再把「无电流采样的电压前馈」当作唯一路径。  
> 对照：无电流方案 [`tau_pwm_calibration_sop.md`](tau_pwm_calibration_sop.md) · 总路线 [`stage5.md`](stage5.md) · AT8236 衰减 [`pwm_fast_slow_decay.md`](pwm_fast_slow_decay.md)

本文是**规划流程**（选型 → 接线 → 标定 → 固件分层 → 切 LQR），不是立刻写代码的清单。  
原则：**先能测准电流，再谈力矩标定，最后才上电流内环 / LQR。**

---

## 0. 为什么加电流传感后路径要重画

| | 无电流（旧） | **有电流（本规划）** |
| --- | --- | --- |
| 力矩怎么来 | 用 \(R,K_b,V,\omega\) 反推，误差大 | \(\tau = K_t I_{\mathrm{meas}}\)，直接 |
| 必须精标的量 | \(R,K_t,K_b,D_{\mathrm{dead}},V_{\mathrm{batt}}\) 全套 | **\(K_t\) + 电流通道标定**为主；\(R/K_b\) 降级为可选前馈 |
| 执行器目标 | 开环 τ→PWM 电压公式 | **优先：电流内环跟踪 \(I_{\mathrm{ref}}=\tau_{\mathrm{ref}}/K_t\)** |
| LQR 的 \(u\) | 易与真实力矩脱节 | 可真正贴近 N·m |

有电流后，阶段 5 的硬门槛从「电压前馈常数全对」变成「**电流测得准 + \(K_t\) 标得准 +（可选）电流环带宽够**」。

---

## 1. 总体路线（五段，顺序固定）

```text
P0  硬件选型与接线（左右轮各一路双向电流）
      ↓
P1  电流通道标定（ADC → 安培，含零点/极性/带宽）
      ↓
P2  力矩标定 Kt（挂重 + 电流计；交叉验收）
      ↓
P3  执行器架构：开环 PWM 观测 → 电流 PI 内环 → τ 接口
      ↓
P4  物理参数 + 离散 LQR(K) + 与手调 A/B
```

**禁止**：电流还没过 P1，就改 `BalanceController` 输出单位或上 LQR。

与旧无电流 SOP 的关系：

- [`tau_pwm_calibration_sop.md`](tau_pwm_calibration_sop.md) **不必整份重做**；其中堵转 \(R\)、空载 \(K_b\) 变成**可选**（用于电流环电压前馈或排障）。  
- 死区、软停、`kff`、偏航差速**保留**；它们与「有没有电流」正交。

## 2. P0：硬件选型与接线规划

### 2.1 需求（按本车约束写死）

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 路数 | **左右各 1**，共 2 | 差速 / 单侧故障可诊断 |
| 方向 | **双向**（能测正负电流） | 前进/后退、再生/刹车都有电流反号 |
| 量程 | 建议峰值 ≥ **±5~10 A**（按实车堵转电流留 1.5× 余量） | 堵转标定与摔倒恢复瞬间会冲电流 |
| 带宽 | 模拟前端 ≥ **数 kHz**；数字滤波后给控制用 ≤ 1 kHz | AT8236 PWM 有纹波；控制环 200 Hz 只需平均电流 |
| 隔离 | 分流+放大或霍尔隔离均可 | 注意与 ESP32 GND / 电机功率地布局 |
| MCU | ESP32 ADC（或外置 ADS1115 等） | 若用片上 ADC：注意衰减、噪声、采样时刻 |

### 2.2 推荐传感器形态（选型决策）

按「省事 → 准」排序，现场择一：

| 方案 | 例子 | 优点 | 风险 |
| --- | --- | --- | --- |
| A. 霍尔电流模块 | ACS712 / ACS724 等 | 接线简单、隔离好 | 零点温漂、噪声大，要好好校零 |
| B. 高端/低端分流 + 电流检测运放 | INA240 / INA180 + 分流电阻 | 带宽好、线性好 | 布线/共模电压要设计对；低端分流改地回路 |
| C. 驱动芯片自带电流镜 | 视驱动是否引出 | 集成 | AT8236 **通常不直接给精确双向传感**，本车默认外挂 |

**本规划默认：方案 A 或 B，外挂两路，串在各电机电源回路（推荐测**电机相电流**或半桥供电支路，且与 PWM 同步采样策略一致）。**

### 2.3 接在哪里（概念）

```text
电池 VM ──┬── AT8236(L) ── 电机 L
          │       ▲
          │    电流传感 L（测该桥输出支路电流，符号与前进一致）
          │
          └── AT8236(R) ── 电机 R
                  ▲
               电流传感 R
```

注意：

1. **慢衰减 / 快衰减**会改变续流路径，采样点选错会出现「占空比高但电流读数怪」。选型后在 P1 用示波器或高速采样核对。  
2. 传感器输出 → ESP32 ADC 引脚：**远离电机线绞合、加 RC、共地单点**。  
3. `config.h` 预留：`kCurrentAdcGpio[2]`、量程、零点、符号。

### 2.4 P0 验收（Gate H）

- [ ] 左右各一路物理装完，空载可上电  
- [ ] 万用表/钳表与模块同向通电时，极性约定写进笔记（**前进为正电流**）  
- [ ] 短路/反接保护想清楚（分流电阻功率、反向电压）  
- [ ] 引脚不与现有电机 PWM（23/22、13/12）、I2C（18/19）冲突  

**Gate H 未过 → 不做固件采样。**

## 3. P1：电流通道标定（ADC → 安培）

目标：得到可靠的

\[
I_{\mathrm{meas}} = k_{\mathrm{adc}}\,(\mathrm{ADC}-\mathrm{ADC}_0)
\]

（或厂家 mV/A 曲线 + 实测斜率）。**这一步测的是「安培准不准」，还不是力矩。**

### 3.1 子步骤

| 步骤 | 内容 | 做法 |
| --- | --- | --- |
| P1-1 零点 | 电机使能、PWM=0 或断开负载 | 采 1~2 s 平均 → `ADC0`；上电每次可重校 |
| P1-2 极性 | 开环小正转 `e +20` | \(I\) 应为正；反了软件翻符号 |
| P1-3 斜率 | 串入实验室电流表 / 钳表 | ≥3 个稳态电流点，拟合 \(k_{\mathrm{adc}}\) |
| P1-4 滤波 | 原始 ADC 含 PWM 纹波 | 一阶低通或移动平均；控制用截止建议 **50~100 Hz**（先别滤太狠） |
| P1-5 同步（可选增强） | 在 PWM 周期固定相位采样 | 减小纹波折合误差；P3 再做也不迟 |

### 3.2 记录与验收（Gate I）

| # | 判据 | 阈值 |
| --- | --- | --- |
| I1 | 零点重复（上下电 3 次） | 折合 ≤ **50 mA** |
| I2 | 与外接电流表比（中等电流） | \(\lvert I_{\mathrm{sens}}-I_{\mathrm{meter}}\rvert / I_{\mathrm{meter}} \le **5%**\) |
| I3 | 正负对称 | 同 \|PWM\| 正反，\|I\| 差 ≤ 8% |
| I4 | 静止噪声峰峰值 | 折合 ≤ **100 mA**（滤波后） |
| I5 | 200 Hz 控制环读取不拖垮 `hz` | `ovr` 仍≈0 |

**Gate I 未过 → 禁止用 \(I\) 算 \(K_t\)，更禁止电流环。**

遥测建议增加：`iL` / `iR`（A），便于和 `eff` 对照。

## 4. P2：力矩常数 \(K_t\) 标定（电流方案核心）

> **可执行 SOP + 空白记录表**：[`current_to_torque_calibration_sop.md`](current_to_torque_calibration_sop.md)（Gate I → Gate Kt-I）。

有可靠 \(I\) 后，挂重变成标准做法：

\[
\tau = m g r,\qquad K_t = \frac{\tau}{I_{\mathrm{meas}}}
\]

### 4.1 流程（比无电流版更干净）

1. 轮离地或台架；绳 + 已知 \(m\)；力臂 \(=r\)  
2. 缓慢加大 PWM，直到**匀速**拉起（加速度≈0）  
3. 读稳态 \(I_{\mathrm{meas}}\)（用已校准通道，可同时记外接表交叉）  
4. ≥3 档质量 × 左右轮 × 正反（反可用反向挂或反转）  
5. 定稿 \(K_{t,L}, K_{t,R}\)

### 4.2 验收（Gate Kt-I）

| # | 判据 | 阈值 |
| --- | --- | --- |
| K1 | 同档两次 \(K_t\) 差 | ≤ 8% |
| K2 | 不同质量算出的 \(K_t\) 极差 | ≤ 12% |
| K3 | 左右差 | ≤ 15%（可分填） |
| K4 | 与可选空载 \(K_b\)（若做） | \(e_{tk}\le 20\%\) 为佳；失败以**挂重 \(K_t\)**为准 |

可选交叉（降低优先级）：

- 堵转：短时测 \(R\approx V/I\)（排障用）  
- 空载：\(V\approx K_b\omega\)（给电流环电压前馈用，不是力矩主路径）

### 4.3 本阶段交付物

```text
I_meas 通道参数（零点、斜率、符号、滤波）
Kt_L, Kt_R
验证：τ_hat = Kt * I 在挂重工况与 mgr 差 ≤ 15%
```

**Gate Kt-I 过关后，才具备「力矩测量」能力。**  
此时即使还没有电流环，也可以用 \(\hat\tau\) 做遥测与手调/% 输出的对照标定。

## 5. P3：固件架构规划（推荐分三刀）

不要一次上「LQR + 电流环 + 新单位」。拆成：

### 5.1 刀 1 — 只观测（不改控制）

| 项 | 内容 |
| --- | --- |
| 代码 | ADC 采样 → `I` → \(\hat\tau=K_t I\)；打进 `ControlSnapshot` |
| 控制 | 仍输出占空比 %（现网手调） |
| 验收 | 站立时 \(\hat\tau\) 与 `eff` 同趋势；挂重开环 \(\hat\tau\approx mgr\) |

**目的**：证明传感在实车振动/平衡电流下仍可用。

### 5.2 刀 2 — 电流内环（力矩执行器真正落地）

结构：

```text
Balance / LQR
    u = τ_ref  (N·m)
         ↓
    I_ref = τ_ref / Kt
         ↓
    电流 PI（+ 可选电压前馈 Vff = I*R + Kb*ω）
         ↓
    PWM → AT8236
         ↑
    I_meas（反馈）
```

| 项 | 建议 |
| --- | --- |
| 环频率 | 电流环 **1~2 kHz**（若算力不够，至少与 PWM 同级或 500 Hz+）；外环平衡仍 **200 Hz** |
| 限幅 | \(I_{\max}\)、PWM 饱和、积分 anti-windup |
| 死区 | 可放在电流环外：\(\lvert I_{\mathrm{ref}}\rvert\) 过小则 PWM=0；或保留很小的 \(D_{\mathrm{dead}}\) |
| 衰减模式 | 维持现有慢衰减；改衰减后要重验电流采样与环路 |

**刀 2 验收（Gate C）**

| # | 判据 |
| --- | --- |
| C1 | 阶跃 \(I_{\mathrm{ref}}\)（架空）：跟踪稳态误差 ≤ 5~10%，无持续振荡 |
| C2 | \(\tau_{\mathrm{ref}}\) 阶跃：\(\hat\tau\) 跟上，超调可接受 |
| C3 | 切入平衡后：不比纯 % 手调更抖；`hz/ovr` 正常 |
| C4 | 过流保护：超 \(I_{\max}\) 削幅并打 fault 位 |

### 5.3 刀 3 — 控制环输出改 N·m + 换 \(-K_{\mathrm{LQR}}\)

| 项 | 内容 |
| --- | --- |
| 接口 | `WheelActuator::applyTorque(τ)` → 写 `I_ref`（不再直接写死电压公式） |
| 限幅 | `kMaxEffort` 从 % 改为 N·m（或改名 `kMaxTorque`） |
| 增益 | 手调先按「等价力矩」跑通 → 再换离散 LQR 的 \(-K\) |
| 保留 | `vref_smooth`、`kff`、`pos_ref`、yaw 差速 |

**与旧 τ→PWM 电压公式**：有电流内环后，**主路径不再依赖**整份电压前馈 SOP；电压公式最多做 PI 的前馈项。

## 6. P4：切 LQR（在电流力矩链路通了之后）

与 [`stage5.md`](stage5.md) 相同，但执行器前提换成「电流环已过 Gate C」：

1. 实测 \(M,m,l,I,\ldots\)（仍不能抄仿真）  
2. `dt=0.005` 与 `hz=200` 一致  
3. 仿真侧 `lqr_gain_design.py` 算离散 \(K\)（\(u\) 单位 = N·m）  
4. 固件填 \(-K\)，与手调 A/B  
5. 过关：不差于手调；抖/跟踪/停稳可量化对比  

出问题排查顺序（有电流版）：

```text
I 通道（零点/极性）→ Kt → 电流环带宽/限幅 → l / 模型 → Q/R → 状态符号
```

## 8. 风险清单（开工前看一眼）

| 风险 | 症状 | 缓解 |
| --- | --- | --- |
| PWM 纹波进 ADC | \(I\) 跟着抖，电流环啸叫 | 模拟 RC + 数字 LPF；同步采样 |
| 零点温漂（霍尔） | 静止有虚假力矩 | 上电校零；定期 `I≈0` 时刷新 |
| 采样点与续流路径不符 | 占空比↑电流读数反常 | 对照 [`pwm_fast_slow_decay.md`](pwm_fast_slow_decay.md) 改采样点 |
| 双死区 | 又 `kMotorDeadband` 又电流死区 | 合并策略，只留一层 |
| 算力 | 2 kHz 电流环拖垮 200 Hz | 电流环放 Core1 紧循环；通信仍 Core0 |
| 误把传感当闭环 | 只加了 ADC 仍输出 % | 明确处于刀1/刀2/刀3 哪一刀 |

## 9. 决策摘要（给你拍板用）

1. **加电流传感器后，阶段 5 主路径改为：测 \(I\) → 标 \(K_t\) → 电流内环跟踪 \(\tau\) → 再上 LQR。**  
2. 无电流电压前馈 SOP **降级为可选/排障**，不再挡 LQR 的唯一大门。  
3. 固件必须 **刀1（观测）→ 刀2（电流环）→ 刀3（N·m + LQR）**，禁止跳步。  
4. 软停 / 倾角前馈 / 偏航 **不动**，与传感正交。

## 10. 下一步（实现时按这个拆任务）

当你采购/接线方案定了之后，实现顺序建议：

1. `config.h`：ADC 引脚、量程、\(K_t\)、滤波系数  
2. 新建薄层 `CurrentSense`（或放 `WheelActuator`）：raw→A  
3. 遥测打出 `iL/iR`、`tau_hat`  
4. 台架跑完 Gate I / Kt-I  
5. 再开电流 PI 与 `applyTorque`

若你已选定具体芯片型号（例如 ACS724 ±10A / INA240），把型号和打算串入的电路位置发我，可以把本文 **P0 接线**收成一页「引脚+BOM+采样公式」的实施页。
