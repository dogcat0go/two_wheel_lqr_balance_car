# 电流 → 力矩标定 SOP（ACS712 路径）

> 适用：本车已装左右 ACS712-05B，固件 `stage2` 开环可读 `iL/iR`  
> 规划总览：`[stage5_current_torque_plan.md](stage5_current_torque_plan.md)` · 阶段 5 总路线：`[stage5.md](stage5.md)`  
> 对照（无电流电压前馈）：`[tau_pwm_calibration_sop.md](tau_pwm_calibration_sop.md)`（本文**不必**先做 R/K_b）

本文是**可照着做的操作规程**：Gate I（电流准）→ Gate Kt-I（挂重得 K_t）→ 冻结参数。  
未过当前关卡，**禁止**用 I 算力矩，更禁止电流环 / LQR。

---

## 0. 目的与当前硬件状态

### 0.1 目的

得到左右轮力矩常数，使

\hat\tau = K_t I_{\mathrm{meas}}

在挂重准静态工况下与物理力矩 \tau = m g r 一致（见验收阈值）。

### 0.2 当前固件 / 接线（写死，改了就改本文）


| 项   | 现状                                                         |
| --- | ---------------------------------------------------------- |
| 传感器 | ACS712ELC-05B，±5 A，185 mV/A，**模块 VCC=5 V**                 |
| ADC | L=`GPIO34`，R=`GPIO35`（ADC1）                                |
| 符号  | `kCurrentSign[]`（前进为正；反了翻对应项）                              |
| 滤波  | 仅一阶低通 `kCurrentLpfAlpha`；`current()` 闭环用，`currentRaw()` 对照 |
| 遥测  | `m 0`：`iL/iR`（低通）+ `rawL/rawR`（本拍）+ `eff` + `v`            |
| 限幅  | 开环测满占空比时确认 `kMaxEffort` 够大（勿被 60% 裁掉）                      |
| 几何  | r= `kWheelRadiusM` = **0.0375 m**（卡尺复核）                    |


公式（固件已实现，斜率用厂家标称；Gate I 用外接表核对）：

I = \mathrm{sign}\cdot\frac{V_{\mathrm{out}}-V_0}{0.185},\quad
V_0=\text{上电校零}

## 3. Gate Kt-I：挂重标定 K_t

### 3.1 原理

准静态（加速度 ≈ 0）：

\tau = m g r,\qquad
K_t = \frac{\tau}{I_{\mathrm{meas}}}

- g = 9.81\mathrm{m/s^2}  
- r = 0.0375\mathrm{m}（先填卡尺实测再算）  
- I_{\mathrm{meas}} 用固件**已通过 Gate I** 的 `iL` 或 `iR`（低通）；可同时记外接表交叉

**必须匀速上升**（或恰好顶住）。加速拉起 → I 偏大 → K_t 偏低。

例：m=0.100\mathrm{kg}，r=0.0375\mathrm{m}：

\tau = 0.100\times 9.81\times 0.0375 \approx 0.0368\mathrm{N\cdot m}

若 I=0.40\mathrm{A}，则 K_t \approx 0.092\mathrm{N\cdot m/A}。

### 3.2 操作（每轮分开）

1. 该轮离地；绳绕轮缘，力臂 = r
2. 挂质量 m（≥ 3 档）
3. 只驱动该轮：`el` 或 `er`，从低往上缓慢加，直到砝码**匀速**上升
4. 稳态读 `i*`（可看 3~5 行取平均）；记下对应 `eff`
5. 同档重复 2 次；换档、换轮、（可选）反向挂重

### 3.6 Gate Kt-I 验收


| #   | 判据                        | 阈值         | □   |
| --- | ------------------------- | ---------- | --- |
| K1  | 同档两次 I 极差                 | ≤ 8%       |     |
| K2  | 不同 m 算出的 K_t 极差           | ≤ 12%      |     |
| K3  | 左右 K_t 差                  | ≤ 15%（可分填） |     |
| K4  | 挂重工况 \hat\tau=K_t I 与 mgr | 相对差 ≤ 15%  |     |


不合格返工：

1. 是否真匀速（看 `v` 是否近似恒定）
2. 绳打滑 / 力臂 ≠ r
3. Gate I 斜率是否又漂了
4. 「顶住」点静摩擦大 → **扔掉**，只用匀速↑

**Gate Kt-I 过关后**，才具备力矩测量能力；可在遥测加 \hat\tau_L=K_{tL} iL（固件刀 1），仍不必上电流环。
