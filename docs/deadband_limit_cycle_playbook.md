# 电机死区与极限环排查方法论

来源：stage6 E3/E4 实战（2026-08-23，三轮 log 迭代）。所有阈值均为本车实测校准，
换车需重标，但流程与判据结构通用。

核心原则：**先定性、再量化、后调参；每步有数字判据；一次只动一个变量；
异常值优先查机械，不进补偿泥潭。**

---

## 0. 前置条件（顺序不能倒）

1. **电流零点可信**（E0）：静止 |craw| < 10mA 且不随时间走。零点漂着，
   所有力矩数据都是假的，后面全部作废。
2. **trim 无直流**（E3）：v_dc 均值 ≈ 0。爬行的直流分量会污染所有振荡统计。
3. 遥测频率：诊断跑用 `f 50`（20Hz）；5Hz 只够算幅度/周期，看不见波形形状与
   死区跳变（<100ms）。必备字段：pitch/ref、v_l/v_r、tau_l/r、effort_l/r、
   iref/i、v_dc、hold、fault。

## 1. 极限环定性：死区型还是滞后型

同一份 log 算三个指纹，互相印证：

| 指纹 | 算法 | 死区/粘滑型 | 滞后型 |
|---|---|---|---|
| 粘着占比 | \|v\|<0.008 m/s 的时间比例 | >15~20%，成段（0.1~2s） | ≈0，速度连续 |
| τ→v 相位 | 互相关峰的滞后 | 小（<30°），r 高 | 接近 90°+ |
| 波形形态 | 目视 20Hz 波形 | 张弛锯齿：慢爬升+尖峰+回落 | 近正弦，包络对称 |

- pitch 尖峰**单边**（一个方向多）→ 附加判定：正反方向死区不对称。
- 判成滞后型 → 走电流环带宽/电压前馈路线（E1 预案），别动死区。
- 本车实测（E4）：粘着 20~27%、相位 17°、张弛波 → 死区型实锤。

## 2. 死区量化：在线起转事件统计（不用架空）

**起转事件**：|v| 从 <0.008 跨到 ≥0.008 的拍。对每个事件记录该拍的
|τ|、|i|、|duty|，按 轮×方向 分四格取中位数：

|  | 正向 | 反向 |
|---|---|---|
| 左轮 | τ / I / duty% | τ / I / duty% |
| 右轮 | τ / I / duty% | τ / I / duty% |

三个对照读法：

1. **起转 τ vs kTorqueEps**：≫ 门槛 3 倍以上 = 补偿不足（PI 在爬坡，
   爬坡时间就是极限环攒力段）。
2. **四格间差异**：单格异常（如本车 R反 73mN·m vs 其余 15~33）→ 先查机械
   （手转对比正反阻力、齿轮箱卡滞），不是调参问题。正反 2:1 → 单值补偿的
   结构性天花板，考虑分方向死区。
3. **左右电气排除**：i−iref 残差统计、duty/A 回归斜率。两轮相同（本车 58.2
   vs 55.5 %/A）→ 差异在机械静摩擦，不是电流环。

## 3. 补偿闭环：b 标定 + 欠补系数

- `b` 架空标定量的是**电机+齿轮箱内摩擦**，天然低于地面起转门槛，存库值 =
  kCalibScale × (正+反)/2，**只在标定时生效**——改 scale 必须重跑 b。
- scale 的物理含义：运动段动摩擦 < 静摩擦，满补必过补。调整用二分逼近：

```text
欠补指纹：粘着占比高、τ 攒到数倍门槛才起转、张弛尖峰  → scale 上调一档 (0.7→0.85)
过补指纹：v 高频变号(>5 次/s)、嗡嗡、轮子打摆         → scale 退半档 (0.85→0.80)
```

- 每改一档：重烧 → `b` 重标（核对开机 deadband 打印涨幅）→ 同款 3 分钟 log
  → 第 4 节固定口径对比。

## 4. 每轮 log 的固定统计口径（可比性的关键）

稳态段（去掉武装后前 20s 与结尾 5s）算：

- 粘着占比、粘着段数/平均时长/最长；
- 起转 τ 中位 2×2 表；
- pitch−ref 的 mean（trim 残差）与 sd（摆动能量）、极值与单边计数；
- v 振荡周期（过零率）与变号率（过补报警）；
- v_dc mean/sd（爬行/噪声）；
- HOLD 段数与时长（终极验收：能站 60s）;
- yaw 极值与 ui（左右不对称的影子指标）。

## 5. 已踩过的坑（每条都有 log 佐证）

1. **k_s 过大放大极限环**：0.5（3.4× 设计值）使 pitch σ 1.33°→1.97°、周期
   2.7s、HOLD 从偶进变零进。位置增益决定摆多快，消不了摆；回设计值 0.147。
2. **倒下时轮速是伪信号**：车体旋转 + 电机被反拖，编码器读数不代表对地速度，
   轮速差同步项会劫持共模救车力矩（u_sync 已加 one_stuck 门控）。
3. **HOLD 期间 v_dc 不度量 trim 误差**：PWM=0 滑行，微坡缓滚会污染 trim
   伺服 bias（已加 freeze 门控）。
4. **单格机械异常 > 一切参数**：R反 73mN·m 直接导致后倾救车失败摔车。
   调参前先把四格量出来看有没有离群值。
5. **架空标定 ≠ 地面门槛**：系统性偏低是设计使然（负载无关部分），缺口由
   scale 和电流环 PI 分担，不要试图用 scale=1 硬填。

## 6. 决策树

```text
20Hz log 3min
 ├─ 三指纹 → 滞后型？ → E1 路线（电流环带宽/电压前馈），停
 └─ 死区型
     ├─ 2×2 起转表有离群格？ → 查机械（手感/拆检），修完重测
     ├─ 起转 τ ≫ 3×门槛（欠补）？ → scale 上调一档 → b 重标 → 重测
     ├─ v 高频变号/嗡嗡（过补）？ → scale 退半档 → b 重标 → 重测
     ├─ 正反 2:1 且卡 HOLD？ → 分方向死区（meas_ 已分测，存储/查表加一维）
     └─ 指标合格（粘着<10%、pitch σ<1°）→ 调 HOLD 门（enter_ticks/vel_in）→ E4 验收
```
