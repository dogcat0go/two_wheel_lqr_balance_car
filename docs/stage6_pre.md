## 第一组：力矩通道可信化

**E0 验证在线零点跟踪（刚写完的代码）**
烧录后两个动作：上电静置不 `r`，看 `craw` 是否几秒内从 ±17mA 收敛到 0 附近；`el 30` 跑 2 分钟后 `s` 停机扶稳，看 `craw` 是否从漂移值自动缩回 0（τ≈2s）。
过关：静止时 |craw| < 10mA 且不随时间走。

**E1 电流环小信号阶跃（= 原 T2，架空）**
`cl 0.05` → `0.1` → `0.2` → `0.5`，每档 5s，再来一遍负方向。看 `craw` 追 `iref` 的上升拍数、稳态误差、有无振铃。
过关：0.1A 档稳态误差 < 10%，上升 ≤ 3 拍，无持续振铃。
不过关的预案（按推算电流环带宽只有 ~16Hz，大概率要动）：加电压前馈 `duty_ff ≈ (R·i_ref + ke·ω)/V_bat`，PI 只修残差；或减小电流 LPF 滞后。**这步不过关，后面所有"力矩"都是假的，必须停下来修。**

**E2 站立振荡定性（= 原 T3）**
`m 3` + `r` 站立 30s 抓 log。只看三样：`tau` 波形是"长平台 + 跳变"（死区极限环）还是近正弦（滞后主导）；pitch 与 v 的相位；振荡周期。
产出：确定 E3/E4 阶段主要修 Karnopp 门槛还是修滞后，不用猜。

## 第二组：平地定点

**E3 消爬行——v_dc trim 伺服（需写码，约 10 行）**
`bias += −k·v_dc·dt`，门控：`balancing && |v_cmd|<eps && !on_slope`，限幅 ±2°，时间常数 10–20s。替代已关闭的 TrimObserver，专治每次上电机械平衡角偏移。
过关：冷启动 `r` 之后**不碰 `t`**，60s 内 `v_dc → 0`，车不再单向爬。
附带动作：零漂修复后复核 Karnopp 门槛——`kTorqueEps=9mN·m` 对应 39mA，现在零漂被吃掉、LPF 噪声只有 ~10mA（2.3mN·m），这个门槛可以保留观察，E2 说是死区型再调。

**E4 开 k_s，进 HOLD**
前提 E3 过关（趋势项没了）。k_s 从设计值的 1/3（≈0.05）起步逐步回到 0.147，确认不激发振荡。
过关（这就是平地终验收）：静置定点 ±5cm 内进 HOLD（只出 pitch+rate）60s 不出；`v 0.15` 能走不点头；`v 0` 能停不长退。
注：HOLD 不再 PWM=0。轮接近停转时零点跟踪门仍可开；电流环继续跟重力项。

## 第三组：坡

**E5 坡度前馈开环喂角（代码已接好，`q`/`h`）**
先平地 `q 2.8 h 0.5` 验接线：`ref` 应抬 ≈ `K_EQ·h·sin(q)` ≈ 3°，`tff` ≈ 0.011 N·m。再上 3° 板：`q 3`，`h` 从 0.7 → 1。
过关：3° 板上车体稳在 θ_eq 附近，LQR 反馈力矩（`u pit` 等各项）稳态接近 0，不持续爬。
两个已有的门自动生效，确认即可：坡上 `on_slope` 禁 HOLD；E3 的 v_dc 伺服照 `freeze=on_slope` 冻结。坡上 PWM≠0，零点跟踪自动关闭，无冲突。

**E6 标摩擦系数 c（离线，一次性）**
平地 `v 0.15` / `v 0.25` 各匀速跑一段，录 τ（两轮和）与 v。过原点最小二乘 `c = Σ(v·y)/Σv²`，其中 `y = τ/r − m·v̇`。
过关：两段独立 log 算出的 c 相差 < 20%；用 c 复算后 `z_dyn = τ/r − m·v̇ − c·v` 的平地均值不随速度走。**E1 若加了电压前馈，τ 用换算后的实际值，这就是 E1 排在最前的原因。**

**E7 坡度估计器，只出遥测不入环**
一维估计 α̂（先用一阶低通的 z_dyn 就够，KF 可以后补），200Hz 与 LQR 同拍，输入是**上一拍实际下发的总力矩（含前馈）**。
过关：平地静立和巡航 α̂ = 0 ± 1°、不随速度漂；抬上 3° 板 α̂ ≈ 3° ± 1°，坡上停住 5s 不塌回 0。

**E8 α̂ 入环，替掉手动 `q`**
死区 0.015 + 低通 τ≈0.5s + 使能斜坡，θ_eq 与 τ_ff 共用同一 `sin_eff`（代码结构已是这样）。
过关：平地行为退回 E4（α̂≈0 时无感）；3° 板上不需要手动 `q`，车自动前倾到位。

**E9 终验收：坡道定点**
车从平地开上 3° 板中途 `v 0`：停点漂移 < 5cm、保持 30s、α̂ 稳定、稳态电流 ≈ τ_ff/Kt。通过后换 5° 板重复。
