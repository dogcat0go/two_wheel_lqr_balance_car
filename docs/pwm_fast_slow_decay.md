# H 桥 PWM 快衰减与慢衰减原理

> TWIP 平衡车 · 实车执行器层（AT8236）
> 对应代码：`lib/Esp32McpwmMotor/Esp32McpwmMotor.cpp`（`MCPWM_MOTOR_SLOW_DECAY`）
> 配套文档：[τ→PWM 标定](./motor_torque_pwm_calibration.md) · [Sim2Real 阶段 0](./Sim2Real_list.md#phases)

本文说明有刷直流电机 H 桥在 **PWM 调速** 时，「关断半周」里电流如何衰减，以及为何这会影响**启动死区**和低速力矩。不涉及改接线，只讲 IN1/IN2 波形组合。

---

## 先记住 H 桥的四种静态状态 {#states}

以 AT8236 为例（与多数双输入 H 桥同类）：

| IN1 | IN2 | OUT1 / OUT2 | 名称 | 电枢两端 |
| --- | --- | --- | --- | --- |
| 1 | 0 | H / L | 正转驱动 | 施加约 \(+V_M\) |
| 0 | 1 | L / H | 反转驱动 | 施加约 \(-V_M\) |
| 1 | 1 | L / L | 刹车（短接） | 两端被下管短接 |
| 0 | 0 | 高阻 | 滑行 / 休眠 | 断开，靠体二极管续流 |

PWM 调速并不是第三种电源，而是在一个周期里**在「驱动」和某一种关断态之间快速切换**。关断态选「高阻」还是「刹车」，就分成快衰减 / 慢衰减。

---

## 电枢电流为什么要「衰减」 {#why-decay}

电机绕组是电感。驱动导通时电流上升；PWM 关断时电流不能突变，必须经续流回路慢慢降下来，这叫**电流衰减（current decay）**。

衰减快慢取决于关断时回路的等效电压和电阻：

- 回路把能量较快泄掉 → **快衰减**
- 回路几乎短接、主要靠绕组电阻慢慢耗 → **慢衰减**

平均电流（≈ 平均力矩）不仅取决于占空比，也取决于关断半周衰减有多快。

---

## 快衰减（Fast Decay） {#fast}

### 波形（正转）

| 半周 | IN1 | IN2 | 桥状态 |
| --- | --- | --- | --- |
| PWM 高 | 1 | 0 | 正转驱动 |
| PWM 低 | 0 | 0 | 高阻 / 滑行 |

本工程原厂逻辑即此：

- 正转：`IN1 = PWM`，`IN2 = 0`
- 反转：`IN1 = 0`，`IN2 = PWM`

### 电流路径（直觉）

1. **驱动半周**：电源经上管/下管给电枢充电，电流沿驱动方向增大。  
2. **关断半周**：两输入为低，输出高阻；电感电流经 **MOS 体二极管** 续流，两端等效承受接近电源量级的反向电压，电流下降快。

### 特点

| 优点 | 缺点 |
| --- | --- |
| 电流跟占空比更「干脆」，减速/换向相对利落 | 低占空比时平均电流容易上不去 |
| 实现简单：一脚 PWM、一脚拉低 | **启动死区往往偏大**（静摩擦区难建立力矩） |
| 关断时接近滑行，制动感较弱 | 二极管续流有压降，损耗与噪声可能更大 |

本车在快衰减下曾出现：占空比约 **55%～60%** 才能自行启动，手拨后较低占空比仍可维持——典型「静摩擦 > 低占空比平均力矩」。

---

## 慢衰减（Slow Decay） {#slow}

### 波形（正转）

| 半周 | IN1 | IN2 | 桥状态 |
| --- | --- | --- | --- |
| 一脚固定为高、另一脚 PWM **低** | 1 | 0 | 正转驱动 |
| 同一脚 PWM **高** | 1 | 1 | 刹车（双下管导通） |

AT8236 手册对应关系：

| IN1 | IN2 | 功能 |
| --- | --- | --- |
| PWM | 0 | 正转，快衰减 |
| **1** | **PWM** | 正转，**慢衰减** |
| 0 | PWM | 反转，快衰减 |
| **PWM** | **1** | 反转，**慢衰减** |

### 电流路径（直觉）

1. **驱动半周**：与快衰减相同，电源供电。  
2. **关断半周**：进入 **刹车**：电枢两端被低边短接，续流在绕组电阻上缓慢下降，磁场能量泄得慢，**平均电流更容易维持**。

因此同样的「驱动时间占比」下，慢衰减在低速区往往能给出更大的有效力矩，有利于压启动死区。

### 特点

| 优点 | 缺点 |
| --- | --- |
| 低速/启动平均力矩通常更好 | 关断半周在刹车，阻尼偏大，高速「滑行感」弱 |
| 本车实测启动占空比可降到约 **20%** 量级 | 脚上 PWM 占空比含义与快衰减不同（见下节） |
| 适合轮速环、平衡车细调零位附近 | 持续刹车半周，驱动发热可能略增 |

---

## 关键：慢衰减时「占空比」指什么 {#duty-mapping}

慢衰减正转：`IN1 = 1`，`IN2 = PWM` 时：

- `IN2 = 1` → 刹车  
- `IN2 = 0` → 驱动  

因此 **IN2 脚上的 duty 是刹车时间占比**，不是驱动力度：

\[
D_{\mathrm{drive}} = 1 - D_{\mathrm{IN2}}
\quad\Rightarrow\quad
D_{\mathrm{IN2}} = 100\% - D_{\mathrm{drive}}
\]

本库对外仍保持「`updateMotorSpeed(id, 50)` = 约 50% 驱动力度」，内部对慢衰减做了反相：

```text
brake_duty = 100 - drive
正转: IN1 = 高电平, IN2 = brake_duty
反转: IN2 = 高电平, IN1 = brake_duty
```

若忘了反相：命令 100 会变成一直刹车（不动），命令 0 反而接近满驱动——属于实现错误，不是硬件接反。

电机 OUT1/OUT2 对调、或 IN1/IN2 初始化对调，只改变**旋转方向符号**，**不会**把死区从 55%「变成」20%；死区下降应归因于衰减模式，而非接口接反。

## PWM 载波频率与电机啸叫 {#whine}

**啸叫（高频尖声）几乎都来自 PWM 载波频率，与控制环、增益无关。**

绕组在每个 PWM 开关沿受电磁力反复伸缩（磁致伸缩 + 铁芯振动），振动频率 = 载波频率。
本车原设 **10 kHz**，正落在人耳敏感区（20 Hz~20 kHz）→ 持续尖啸。改到 **20 kHz**
（多数成年人听觉上限之外）后基本消失。

- 慢衰减会让啸叫更明显：关断半周在刹车，绕组里**一直有 PWM 电流**，静止/平衡时也响。
  但**别为消啸叫退回快衰减**（低速力矩会变差），直接抬载波频率。
- 载波频率与占空比**解耦**：改频率不影响死区标定、平衡增益、`updateMotorSpeed` 的百分比含义。
- 代价：20 kHz 开关损耗略高于 10 kHz，小电机可忽略；跑几分钟摸驱动不烫手即可。
- 想更安静可再上 25 kHz，但通常没必要。

**排查口诀（区分现象所在层）：**

| 现象 | 首查层 |
| --- | --- |
| 持续高频**尖啸** | 硬件层：PWM 载波频率（抬到 ≥20 kHz） |
| 低频**前后晃 / 嗡鸣** | 控制层：增益（降 `y` 升 `w`）、死区前馈 |
| 一使能就发散 | 符号 / 参数（见 stage3/4 文档 Step 0） |

## 怎么选 {#choose}

| 场景 | 更倾向 |
| --- | --- |
| 启动死区大、要上速度 PID / 平衡 | **慢衰减**（本车当前默认） |
| 更在意快速滑行、减速干脆 | 可对比快衰减 |
| 最终量产 | 两种都测：\(D_{\mathrm{dead}}\)、空载转速–占空比曲线、温升，选综合更好者 |

经验目标（慢衰减标定后）：启动死区 **≤10%** 较舒适，**≤5%** 更利于平衡；仅软件补偿无法替代过大死区。

---

## 一句话总结 {#summary}

- **快衰减**：PWM 在「驱动 ↔ 高阻」之间切，关断电流掉得快，低占空比力矩弱、死区易偏大。  
- **慢衰减**：PWM 在「驱动 ↔ 刹车」之间切，关断电流掉得慢，低速平均力矩通常更好。  
- 慢衰减时脚上 duty 是**刹车占比**，软件必须换算成驱动力度，本库已处理。
