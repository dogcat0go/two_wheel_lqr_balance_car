1. 符号与 ODE → 控制思路 §2–3 · 理论篇 §5

ODE 全称 / 中文？

Ordinary Differential Equation，常微分方程：未知函数对一个自变量（通常是时间）求导。对比 PDE（偏微分方程）。

\(\dot{\mathbf{x}}\)（你打成 \(x'\)）是导数吗？

是。\(\dot x=\mathrm{d}x/\mathrm{d}t\)。控制/力学常用点号；\(x'\) 有时也表示导数，易混。

\(\dot x=f(x,u)\) 是一阶微分方程吗？

是一阶（向量）常微分方程：最高阶导数是一阶。物理常先给二阶式，再拆成一阶向量形式——物理不变，格式变了。

怎么理解 ODE？是不是积分得下一拍，变数只有 \(Bu\)？

积分直觉对：\(x(t+\Delta t)\approx x+\Delta t\cdot(Ax+Bu)\)。
「只有 \(Bu\)」差半句：下一拍由 \(Ax\)（自然漂移）+ \(Bu\)（你操纵） 共同决定。你能选的只有 \(u\)；从 \(x_0\) 到远处 \(x_1\) 通常要一串 \(u\)，不是一拍到位。

2. 状态方程与 \(A,B\) → 控制思路 §4 · 理论篇 §4.4–5

\(A,B\) 怎么「简化」得到？我矩阵乘法对不上

不是化简，是系数对号入座。 先有一阶式 \(\dot x_1=x_2\)、\(\dot x_2=\ldots\)，再把各式对 \(x_1,x_2,u\) 的系数排进 \(A,B\)。用 \(Ax+Bu\) 验算应回到原一阶式。

\(Ax+Bu\) 第一行的 \(x_2\)「去哪了」？表示什么？

没丢。结果向量第一行就是 \(x_2\)，且 \(\dot x_1=x_2\)。因 \(x_1=q,x_2=\dot q\)，即位置变化率 = 速度（运动学行）。

质量矩阵形如何变成 \(\mathbf{A}_a,\mathbf{B}_a\)？

左乘 \(M_q^{-1}\)：\(\ddot q=M_q^{-1}(\text{重力项}+[b_1;b_2]\tau)\)。再按 \([s,\theta,\dot s,\dot\theta]\) 排成 \(2\times4\) 的 \(\mathbf{A}_a\) 与 \(2\times1\) 的 \(\mathbf{B}_a\)（无摩擦时 \(\dot s,\dot\theta\) 列常为 0）。

为什么左边是 \(M_q[\ddot s;\ddot\theta]\)？

多自由度版的 \(ma\)：耦合时每个方程同时含两个加速度，系数排成 \(M_q\)。来源是动能二次型；拉格朗日后最高阶项必为 \(M_q\ddot q\)。

补全 \(A\) 时，运动学 \(\dot\theta,\dot s\) 的系数？

定义式：\(\dot s=\dot s\)、\(\dot\theta=\dot\theta\)。对应行只在「对准自己速度」的位置填 1，其余 0。\(\mathbf{A}_a,\mathbf{B}_a\) 只填加速度那两行；\(B\) 的运动学两行通常为 0。

\(a_{21},a_{41}\) 与 \(Q_s,Q_\theta\) 关系？

不是一路。 \(a_{21},a_{41}\) ← 重力 \(Mgl\theta\) 经 \(M_q^{-1}\) → 进 \(A\)；\(Q_s,Q_\theta\) ← 力矩虚功 → 经 \(M_q^{-1}\) → 进 \(B\)。

3. 输出方程与可控性 → 理论篇 §5

\(y=Cx+Du\) 是什么？和可控性里的 \(C\) 一样吗？

输出方程：测到/关心的量。\(C\)=输出矩阵，\(D\) 常为 0。
可控性矩阵 \(\mathcal{C}=[B\ AB\ A^2B\ A^3B]\) 是另一个东西（建议写成 \(\mathcal{C}\)），由 \(A,B\) 拼接，不是传感器定义。

可控性原理？为何 \(\mathrm{rank}(\mathcal{C})=4\) 就可控？

\(u\) 经 \(B\) 撬动状态，再经 \(A,A^2,\ldots\) 传到别的方向。能撬的方向 = \(\mathrm{span}\{B,AB,A^2B,A^3B\}\)。rank=4（=状态维数）⇔ 张满 \(\mathbb{R}^4\) ⇔ 完全可控。

细化：4 个 \(\Delta t\)，\(u_0\sim u_3\)

离散：\(x_{k+1}=A_d x_k+B_d u_k\)。四步后：

\[ x_4=A_d^4 x_0+A_d^3 B_d u_0+A_d^2 B_d u_1+A_d B_d u_2+B_d u_3 \]

早施加的 \(u\) 被 \(A_d\) 传得更多。\(\mathcal{C}_d=[B_d\ A_dB_d\ A_d^2B_d\ A_d^3B_d]\) 的列就是这些方向；rank=4 ⇔ 存在 \((u_0,\ldots,u_3)\) 使 \(\Delta x\) 任意。

4. 物理与惯量 → 理论篇 §1 · 参数表

平行轴：本车 \(I_{\mathrm{axis}}\)？

绕轮轴：\(I_{\mathrm{axis}}=I+Ml^2\)。参数表填的 \(I\) 是绕质心，不要把已加 \(Ml^2\) 的数再填进去。

电机重心在轴下怎么算？

\(h_{\mathrm{电机}}\) 填负数；\(l=\sum m_i h_i/M\)（可仍 >0）；\(I_{\mathrm{axis}}=I+Ml^2\) 照旧（用 \(l^2\)）。起步 \(I\approx\sum m_i(h_i-l)^2\)。

\(I\) 与 \(Ml^2\) 是轮 / 车体惯量吗？

都是车体俯仰： \(I\)=车体绕质心；\(Ml^2\)=平行轴贡献。轮惯量 \(I_w\) 进 \(m_{\mathrm{eff}}=m_w+I_w/r^2\)，不在 \((I+Ml^2)\dot\theta^2\)。

\(I_{\mathrm{车}}\)、\(I_{\mathrm{轮}}\) 怎么表示（无数值）？

  • 车：\(I\) 或 \(I_{\mathrm{cm}}\)；绕轴 \(I+Ml^2\)
  • 轮：\(I_w\)；模型里常 \(\to I_w/r^2\) 并进 \(m_{\mathrm{eff}}\)

教材 \(M,m\) 与本仓库 \(M,m_{\mathrm{eff}}\)？

字母对调：教材小车 \(M\) ↔ 本仓库 \(m_{\mathrm{eff}}\)；教材摆 \(m\) ↔ 本仓库车体 \(M\)。按「谁平移 / 谁俯仰」记。

5. 摆与标准二阶系统 → 理论篇 §2 · 增益理论

下垂单摆模型怎么构造？

切向：\(ml\ddot\theta=-mg\sin\theta\) ⇒ \(\ddot\theta+(g/l)\sin\theta=0\)。或支点取矩 / 拉格朗日，同结果。

\(\omega_0=\sqrt{g/l}\) 怎么来？

线性化 \(\ddot\theta+(g/l)\theta=0\)，对照标准形 \(\ddot x+\omega_0^2 x=0\)，认出 \(\omega_0^2=g/l\)。

「标准二阶阻尼系统」是什么？要背吗？

记住 \(\ddot x+2\zeta\omega_n\dot x+\omega_n^2 x=0\)：\(\omega_n\)=快慢，\(\zeta\)=抖不抖。倒立摆增益反解式可现场推，不必死背。

为何系数能表示自然频率、阻尼比？

解的形状里本来就有振荡频率 \(\sqrt{c}\) 与衰减率 \(b/2\)；令 \(c=\omega_n^2\)、\(b=2\zeta\omega_n\) 只是把这两个物理量参数化。

6. 拉格朗日细节 → 拉格朗日篇

倒立摆偏导为何没写全？

已补进 §9.1、§10.6。关键差在 \(\partial L/\partial\theta\) 符号（下垂恢复 / 倒立倾覆）。

式 (10)（\(x\) 方程）怎么从 \(L\) 推到？

  1. \(\partial L/\partial\dot x=(M+m)\dot x-ml\dot\theta\cos\theta\)
  2. \(\mathrm{d}/\mathrm{d}t\) → \((M+m)\ddot x-ml\ddot\theta\cos\theta+ml\dot\theta^2\sin\theta\)
  3. \(\partial L/\partial x=0\)
  4. 左边 \(=Q_x=F(t)\)

为何左边等于 \(F(t)\)？

右边是广义力 \(Q_x\)；只 \(\delta x\) 时 \(\delta W=F\delta x\) ⇒ \(Q_x=F\)。重力在 \(V\) 里，不进 \(Q_x\)。

\(\theta\) 方程求的是什么？为何 =0？

摆角自由度的运动方程。经典小车模型对 \(\theta\) 无外力矩 ⇒ \(Q_\theta=0\)。轮式车常有 \(Q_\theta=-\tau\)，右边不是 0。

\(\mathbf{r}_k\) 是什么？

第 \(k\) 块质量的位置矢量；\(\dot r_k\) 为速度。\(r_k=r_k(q)\)，由此把动能写成 \(\dot q\) 的二次型。

\(Ml\cos\theta\,\dot s\dot\theta\) 该不该负号？

本约定 \(x_M=s+l\sin\theta\) 下是正号。教材出现负号，多半是 \(\theta\) 零点或 \(x=s\pm l\sin\theta\) 定义不同。

为何可写成 \([b_1;b_2]\tau\)？

广义力 \(Q\) 对单个 \(\tau\) 线性：虚功得 \(Q_s=\tau/r\)、\(Q_\theta=-\tau\)（示意）⇒ \(Q=[b_1;b_2]\tau\)，放到 \(M_q\ddot q=\ldots+Q\) 右边。

7. 质量矩阵从哪来 → 拉格朗日 · 理论篇 §4

当前 \(M_q\) 通过什么得来？

写动能 \(T\) → 整理成 \(\tfrac12\dot q^\top M_q(q)\dot q\) → 读出系数。线性化 \(\cos\theta\approx1\) 得常矩阵 \(m_{ij}\)。

\(T=\tfrac12\dot q^\top M_q\dot q\) 背后原理？

直角坐标动能 \(\propto v^2\)；\(v=\sum(\partial r/\partial q_i)\dot q_i\) 对 \(\dot q\) 线性 ⇒ \(T\) 对 \(\dot q\) 二次 ⇒ 必能写成该二次型。

\(m_{11},m_{12}\) 为何是那种形式？

线性化后加速度系数：\(m_{11}=M+m_{\mathrm{eff}}\)，\(m_{12}=m_{21}=Ml\)，\(m_{22}=I+Ml^2\)。来自动能二次型 / 拉格朗日最高阶项，不是另设。

8. LQR 与 \(u^\star\) → 理论篇 §7.2.1–7.5

\(u^\star\) 完整推导链必须含哪些概念？

值函数 → 贝尔曼原理 → DP/HJB → LQ 特化 → \(\min_u\) → CARE/DARE。详见 §7.2.1。

\(V(x+\dot x\,\mathrm{d}t)\) 一阶泰勒怎么展开？

多元：\(V(x+\Delta x)\approx V+(\partial V/\partial x)^\top\Delta x\)；\(\Delta x=\dot x\,\mathrm{d}t\)。列梯度转置后与位移点乘。\(O(\mathrm{d}t^2)\) 在除以 \(\mathrm{d}t\) 后丢掉。→ §泰勒

\(V=x^\top Px\) 时 \((\partial V/\partial x)^\top=2x^\top P\) 吗？

是（\(P=P^\top\)）。列梯度 \(\partial V/\partial x=2Px\)，转置得 \(2x^\top P\)。HJB 里 \((\partial V/\partial x)^\top\dot x=2x^\top P(Ax+Bu)\)。

为何 \(P=P^\top\)？

二次型只依赖对称部分；CARE 在 \(Q\) 对称时解也对称。否则 \(x^\top PBu\) 转置后会出现 \(P^\top\)。

\(u^\top Ru\) 求导为何是 \(2Ru\)？

\(\sum_{i,j}u_i R_{ij}u_j\) 对 \(u_k\) 碰到左右各一次 → \((R+R^\top)u\)；\(R\) 对称 → \(2Ru\)。

矩阵求导时前面为何有 \(B^\top\)？

\(x^\top PBu=(B^\top Px)^\top u\)（用 \(P=P^\top\)）。\(\partial(a^\top u)/\partial u=a\)，\(a=B^\top Px\)。\(B^\top\) 来自 \((PB)^\top\)。

HJB 里对 \(u\) 求最优的步骤？

固定 \(x\)，只留 \(u^\top Ru+2x^\top PBu\)；\(\partial/\partial u=2Ru+2B^\top Px=0\) ⇒ \(u^\star=-R^{-1}B^\top Px\)。Hessian \(2R\succ0\) 确为极小。

代价二次 + 动力学线性 ⇒ 未来代价还是二次型？非线性呢？

LQ 下贝尔曼递推封闭：\(V(Ax+Bu)\) 仍二次，\(\min_u\) 后 \(V\) 仍 \(x^\top Px\)。非线性时 \(V(f(x,u))\) 一般不再二次，真实 \(V\) 无闭式；LQR 只是工作点附近近似。

闭环 \(\dot x=(A-BK)x\) 是否要求特征值为复数？

否。连续稳定要 \(\mathrm{Re}(\lambda)<0\)，可以是负实根。复根只表示有振荡模态。→ §7.4

9. 面试与落地 → stage5 工程文档

理论篇 §4 对轮足运动岗重要吗？

重要（建模基础），但不是唯一重点。能讲清坐标→线性化→状态方程；\(m_{ij}\) 可推更好。架构、接触、估计常更被问。

JD 写了 LQR + 前馈？

§4+LQR 变核心；另练：离散 LQR、\(Q/R\)、\(u=-K(x-x_{\mathrm{ref}})+u_{\mathrm{ff}}\)、车上 kff/软停、力矩单位与 \(\mathbf{B}\)。

C++ 有什么库解 Riccati？直接 SciPy 再填 \(K\) 可以吗？

Eigen 无现成 ARE。推荐 PC：scipy.linalg.solve_discrete_are（先 cont2discrete ZOH，\(dt=0.005\)）。固件只填 \(-K\)（对齐状态顺序、力矩单位）。ESP32 环里不解 Riccati。Drake/CT/SLICOT 可用于 C++ 离线，非本仓库默认。→ §7.5.1
