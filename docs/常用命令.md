# 常用命令

仓库根目录执行。先 source ROS：

```bash
source /opt/ros/humble/setup.bash
```

---

## 烧录 / 监视

```bash
pio run -e stage5 -t upload
pio device monitor -e stage5
```

---

## WiFi 遥测

先起 agent，再上电 ESP，再开桥：

```bash
sudo docker run -it --rm -v /dev:/dev -v /dev/shm:/dev/shm --privileged --net=host \
  microros/micro-ros-agent:$ROS_DISTRO udp4 --port 8888 -v6
```

```bash
python3 tools/fishbot_wifi_bridge.py
```

发命令（另一终端）：

```bash
echo 'r' > /tmp/fishbot_wifi_cmd
echo 't 2.3' > /tmp/fishbot_wifi_cmd
echo 's' > /tmp/fishbot_wifi_cmd
```

手工 echo 话题时须带 best_effort（与 ESP32 QoS 对齐）：

```bash
ros2 topic echo --qos-reliability best_effort /fishbot/log
```

---

## Log → CSV

`-o` 路径写在同一行，不要把 `.csv` 拆开。

```bash
python3 tools/stage3_log_to_csv.py logs/wifi_20260820_162323.log -o logs/hold1.csv
```

省略 `-o` 则写成同名 `.csv`：

```bash
python3 tools/stage3_log_to_csv.py logs/wifi_20260820_162323.log
```

---

## PlotJuggler

需图形界面（有 `$DISPLAY`）。时间轴选 `t_s`。

```bash
source /opt/ros/humble/setup.bash
ros2 run plotjuggler plotjuggler
```

打开已有 CSV：

```bash
source /opt/ros/humble/setup.bash
ros2 run plotjuggler plotjuggler -- -n -d logs/hold1.csv
```
